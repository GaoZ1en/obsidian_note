博弈论主要由以下四类构成

|       | 静态                | 动态                    |
| ----- | ----------------- | --------------------- |
| 完全信息  | 完全信息静态博弈，纳什均衡     | 完全信息动态博弈，子博弈完美/精炼纳什均衡 |
| 不完全信息 | 不完全信息静态博弈，贝叶斯纳什均衡 | 不完全信息动态博弈，精炼贝叶斯纳什均衡   |

而不完全信息动态博弈几乎没有考过，看看就好。

### 博弈的一般论述

任意一个博弈都可以抽象为以下组成部分
1. **参与者**
	1. 进行博弈的各方，用$\displaystyle{i=1,2,\dots,s}$表示
	2. 为了方便描述概率，会引入**自然**/虚拟参与者的概念，用$\displaystyle{N}$表示。在其他所有参与者之前行动，且所有结果对其无差异
2. **行动**
	1. 参与者在博弈某时刻的决策变量，用$\displaystyle{a_{i}}$表示
	2. 所有参与者行动的有序集称为**行动组合**，用$\displaystyle{a=(a_{1},a_{2},\dots,a_{n})}$表示
	3. 有顺序之分，如果参与者同时行动则为**静态博弈**，否则为**动态博弈**
3. **信息**
	1. 参与者有关博弈的知识
	2. **完美信息**指一个参与者对其他参与者的行动选择都有准确的了解
	3. **完全信息**指自然的初始行动被其他参与者准确观察到。显然完美信息包含了完全信息的概念
	4. **共同知识**指所有参与者知道、所有参与者知道所有参与者知道、...的知识
4. **战略**
	1. 参与者在**给定信息**下的行动规则，用$\displaystyle{s_{i}}$表示
	2. 类似于行动组合，有**战略组合**的概念，用$\displaystyle{s=(s_{1},s_{2},\dots,s_{n})}$表示
5. **效用**
	1. 在给定战略组合下，每个参与者的效用
6. **结果**
	1. 在博弈过程中参与者选择了特定的战略组合，就给出一个结果
7. **均衡**
	1. 参与者的**最优**战略组合，记为$\displaystyle{s^{*}=(s_{1}^{*},s_{2}^{*},\dots,s_{n}^{*})}$
	2. 其存在性由各种存在性定理保证。请注意一个博弈的均衡可能是**不唯一**的，需要找出所有的均衡
	3. 请注意一般均衡理论中的均衡指由个人最优化行为导致的一组价格，实际上是博弈论里说的均衡结果

同一个博弈会有不同的表达方法，我们称为**战略式**和**扩展式**。二者完全等价，但战略式更适用于静态博弈，而扩展式更适用于动态博弈

战略式表述需要以下“信息”
1. 博弈的参与者集合$\displaystyle{i\in \Gamma,\Gamma=(1,2,\dots,n)}$
2. 每个参与者的战略空间$\displaystyle{S_{i},i=1,2,\dots,n}$
3. 每个参与者的效用函数$\displaystyle{u_{i}(s_{1},s_{2},\dots,s_{n}),i=1,2,\dots,n}$

对于有限博弈，即参与者有限，且每个参与者的战略空间有限的博弈，可以方便地用表格来表示。比如

| 1\2 | 石头    | 剪刀    | 布     |
| --- | ----- | ----- | ----- |
| 石头  | 0, 0  | 1, -1 | -1, 1 |
| 剪刀  | -1, 1 | 0, 0  | 1, -1 |
| 布   | 1, -1 | -1, 1 | 0, 0  |

对于扩展式表述，等到动态博弈再进行解释

在博弈分析中我们假定参与者都是**理性**的，即每个参与者都能够给出给定信息下最优的战略。现实生活并非如此

### 完全信息静态博弈

**占优战略**：不论其他参与者选择什么战略，该参与者的某一战略均优于其他战略，即效用总是大于其他战略
符号表示：如果对于所有的战略组合$\displaystyle{s}$，都有$\displaystyle{u_{i}(s^{*}_{i},s_{-i})>u_{i}(s^{\dagger}_{i},s_{-i}), \quad\forall S_{i}\ni s^{\dagger}_{i}\not=s_{i}^{*}}$，那么$\displaystyle{s_{i}^{*}}$被称为是严格占优战略，对应的其他$\displaystyle{s^{\dagger}_{i}}$被称为严格劣战略。
如果取等号，那么称为占优战略，其他的战略被称为劣战略

**占优战略均衡**：对于一个均衡，如果每个参与者的战略都是其占优战略，那么这个均衡就被称为占优战略均衡。
占优战略均衡一定是纳什均衡

为了寻找占优战略均衡，引入战略之间的优劣的概念，即若不论其他参与者选择什么战略，参与者A战略的效用均大于B战略，那么称A战略优于B战略
符号表示：如果对于所有的战略组合$\displaystyle{s}$，都有$\displaystyle{u_{i}(s^{1}_{i},s_{-i})>u_{i}(s^{2}_{i},s_{-i})}$，那么$\displaystyle{s^{1}_{i}}$被称为**严格优**于$\displaystyle{s_{i}^{2}}$，否则称为**严格劣**。
如果对于所有的战略组合$\displaystyle{s}$，都有$\displaystyle{u_{i}(s^{1}_{i},s_{-i})\geqslant u_{i}(s^{2}_{i},s_{-i})}$，那么$\displaystyle{s^{1}_{i}}$被称为**弱优**于$\displaystyle{s_{i}^{2}}$，否则称为**弱劣**。

只需要在战略式表述的表格中不断轮流划去每个参与者的严格/弱劣战略，即可得到占优战略均衡
当然**不是所有博弈都有占优战略均衡**

举例

|     | C1    | C2    | C3    |
| --- | ----- | ----- | ----- |
| R1  | 2, 12 | 1, 10 | 1, 12 |
| R2  | 0, 12 | 0, 10 | 0, 11 |
| R3  | 0, 12 | 0, 10 | 0, 13 |

可以看到对于参与者R，其R1战略严格优于R2和R3战略，因此可以将R2，R3行划去

|     | C1    | C2    | C3    |
| --- | ----- | ----- | ----- |
| R1  | 2, 12 | 1, 10 | 1, 12 |

然后对于参与者C，其C2战略严格劣于C1和C3战略，因此可以将C2划去，得到

|     | C1    | C3    |
| --- | ----- | ----- |
| R1  | 2, 12 | 1, 12 |

这样就得到了两个占优战略均衡

（纯战略）**纳什均衡**：对于某一战略组合，如果其中任一参与者改变其战略，它的效用都不会增加，那么称这一战略组合为纳什均衡
符号表示：战略组合$\displaystyle{s^{*}=(s_{1}^{*},s_{2}^{*},\dots,s^{*}_{n})}$被称为纳什均衡，如果$\displaystyle{u(s_{i}^{*},s_{-i}^{*})\geqslant u(s_{i}^{\dagger},s^{*}_{-i}),\forall s_{i}^{\dagger}\in S_{i},\forall i}$
（纯战略）纳什均衡可能不止一个，也可能不存在

对于能够通过重复剔除劣战略得到占优战略均衡的博弈，纳什均衡一定是占优战略均衡
对于不能通过重复剔除**严格**劣战略得到占优战略均衡的博弈，纳什均衡一定存在于没有被剔除的战略组合里
如果剔除了弱劣战略，那么剔除过程可能会将纳什均衡剔除。

对于不存在纯战略纳什均衡的博弈，我们会去求**混合战略纳什均衡**。首先定义**混合战略**的概念
**混合战略**：即参与者以一定的概率选择在某几个行动的集合里进行随机选择的战略。
因此，纯战略可以理解为混合战略的特例

关于混合战略的效用，只需求数学期望即可得到**期望效用**。
进而可以定义**混合战略纳什均衡**。这里就不写符号表示了。

纳什均衡的存在性定理（看看就好）
在$\displaystyle{n}$人完全信息静态博弈中，如果每个参与者的纯战略空间$\displaystyle{S_{i}}$是欧氏空间中非空有界闭的凸集，效用函数是连续的，那么存在一个混合战略纳什均衡
反正就是说必定存在混合战略纳什均衡。

### 完全信息动态博弈

这里涉及到博弈的**扩展式表述**

扩展式表述需要以下“信息”
1. 博弈的参与者集合$\displaystyle{i\in \Gamma,\Gamma=(1,2,\dots,n)}$，包括自然$\displaystyle{N}$
2. 每个参与者的行动顺序
3. 每个参与者的行动空间$\displaystyle{S_{i},i=1,2,\dots,n}$，包括自然的行动，即外生事件的概率分布
4. 每个参与者的信息集
5. 每个参与者的效用函数$\displaystyle{u_{i},i=1,2,\dots,n}$

这里我们把属于同一信息集的节点用虚线连接

所有的战略式表述都可以转变为扩展式表述，反过来也一样
对于扩展式表述的博弈，可以通过转化为战略式表述的方式定义纳什均衡的概念

然而我们想要的是更合理的**子博弈精炼/完美纳什均衡**。首先我们引入**子博弈**的概念

**子博弈**：在扩展式表达中，某个节点后续部分如果没有虚线与博弈的其他部分相连，那么称该节点以下的部分称为子博弈
任何博弈本身都是自身的一个子博弈

**子博弈精炼/完美纳什均衡**：对于一个扩展式表述的博弈，一个战略组合被称为子博弈精炼/完美纳什均衡，如果它是纳什均衡，且在所有子博弈中给出纳什均衡
类似于完全信息静态博弈，存在**纯策略**和**混合策略**的子博弈精炼/完美纳什均衡。
**请注意子博弈完美/精炼纳什均衡需要列出所有参与者在所有子博弈中的战略组合**
鉴于子博弈精炼/完美纳什均衡在所有子博弈中给出纳什均衡，那么可以通过**逆向归纳法**的方式给出子博弈完美/精炼纳什均衡。具体来说，对于一个扩展式表述的博弈，首先列出其所有的“最低级子博弈”，即不存在除自身以外子博弈的子博弈。然后求出最低级子博弈的纳什均衡，并用均衡结果代替原有子博弈，重复这一过程即可得到子博弈精炼/完美纳什均衡

下面给出一个例子

![[../../Attachments/Pasted image 20241218175136.png]]

可以看到最下面的子博弈。我们首先将其转化为战略式表述

| 1\2 | L'    | R'    |
| --- | ----- | ----- |
| U'  | 2, -2 | -2, 2 |
| D'  | -2, 2 | 2, -2 |

可以看到这个子博弈只存在一个混合策略纳什均衡，即$\displaystyle{p_{1U'}=\frac{1}{2}, p_{1D'}=\frac{1}{2}, p_{2L'}=\frac{1}{2}, p_{2R'}=\frac{1}{2}}$，对应的期望均衡结果为$\displaystyle{(0,0)}$。然后将这个均衡结果代替掉原有子博弈，次一级子博弈的纳什均衡结果为参与者2选择战略$\displaystyle{L}$，对应均衡结果为$\displaystyle{(3,1)}$。再次进行替换，最后一级子博弈的纳什均衡结果为参与者1选择战略$\displaystyle{U}$，对应均衡结果为$\displaystyle{(2,2)}$。因此该博弈的子博弈精炼纳什均衡为：在第一步博弈参与者1选择战略$\displaystyle{U}$；若参与者1在第一步博弈选择战略$\displaystyle{D}$，那么参与者2将在第二部博弈选择战略$\displaystyle{L}$；若参与者1在第一步博弈选择战略$\displaystyle{D}$且参与者2将在第二步博弈选择战略$\displaystyle{R}$，那么在第三步博弈参与者1选择分别以$\displaystyle{\frac{1}{2}}$和$\displaystyle{\frac{1}{2}}$的概率选择战略$\displaystyle{U'}$和$\displaystyle{D'}$，同时参与者1选择分别以$\displaystyle{\frac{1}{2}}$和$\displaystyle{\frac{1}{2}}$的概率选择战略$\displaystyle{L'}$和$\displaystyle{R'}$。

有一种特殊的完全信息动态博弈值得讨论，即重复博弈，也就是博弈各方会不断重复第一次博弈。
先来讨论有限重复博弈，即博弈只重复有限次。下面的定理给出了有限重复博弈的子博弈精炼纳什均衡
定理：在有限重复博弈中，如果对于一轮博弈只存在唯一的纳什均衡，那么该有限重复博弈只存在唯一的子博弈精炼纳什均衡，即每一轮博弈均衡均为那唯一的纳什均衡。

对于无限重复博弈，存在完全不同的子博弈精炼纳什均衡。我们称之为**触发战略**
定理：在无限重复博弈中，设$\displaystyle{a^{*}}$为为一轮博弈的纳什均衡，对应的均衡结果记为$\displaystyle{u^{*}}$，设$\displaystyle{a'}$为任意可能的战略组合，对应的效用为$\displaystyle{v'}$。那么对于任意严格优于$\displaystyle{a^{*}}$的战略组合$\displaystyle{a'}$，存在一个贴现因子$\displaystyle{\delta^{*}<1}$使得对于所有的$\displaystyle{\delta\geqslant\delta^{*}}$，$\displaystyle{a'}$是一个特定的子博弈精炼纳什均衡。此时所有参与者按战略组合$\displaystyle{a'}$进行行动，若某个参与者选择了其他的战略，此后所有参与者将按纳什均衡$\displaystyle{a^{*}}$进行行动。

怎么得到这个$\displaystyle{\delta^{*}}$呢，让我们用无限重复的囚徒困境来举例

设一轮囚徒博弈由下表所示

| 1\2 | L    | R    |
| --- | ---- | ---- |
| U   | a, a | B, b |
| D   | b, B | A, A |

其中 B>b, A>a, B>A. 显然存在两个纳什均衡(U, L)和(D, R)，且(D, R)对应的均衡结果相对(U, L)更优。

设贴现因子为$\displaystyle{\delta}$。如果触发战略，即双方选择(D, R)，若一方（不妨设为2）选择$\displaystyle{L}$，那么此后双方选择$\displaystyle{(U, L)}$，成为子博弈精炼纳什均衡，应有2选择L的总效用小于等于选择R的总效用，即

$$\tag{2.1}
\begin{align}
B+\delta a+\delta^{2}a+\dots & \leqslant A+\delta A+\delta^{2}A+\dots \\
B+\frac{\delta a}{1-\delta} & \leqslant \frac{A}{1-\delta} \\
 & \implies \delta\geqslant \delta^{*}=\frac{B-A}{B-a}
\end{align}
$$

所以当$\displaystyle{\delta\geqslant \frac{B-A}{B-a}}$时，触发战略成为子博弈精炼纳什均衡。

### 不完全信息静态博弈

不完全信息博弈体现在至少有一个参与者仅知道其他参与者的效用函数以某个概率取某个形式，或称之为**类型**，记为$\displaystyle{\theta}$，而无法确切的知道其他参与者属于什么类型。
引入海萨尼转换，也就是引入**自然**这一虚拟参与者。自然首先行动决定参与者的特征，这样一个博弈就转换为完全信息（但不完美）博弈。

这里同样可以引入战略式表述
符号表示：$\displaystyle{n}$人不完全信息静态博弈的战略式表述包括以下要素
1. 参与者的类型$\displaystyle{\theta_{1},\theta_{2},\dots,\theta_{n}}$
2. 条件概率$\displaystyle{p_{1},p_{2},\dots,p_{n}}$。$\displaystyle{p_{i}=p_{i}(\theta_{-i}|\theta_{i})}$描述给定参与者$\displaystyle{i}$知道自己的类型为$\displaystyle{\theta_{i}}$时，对于其他参与者类型的不确定性
3. 参与者依赖于自身类型的战略空间$\displaystyle{A_{1}(\theta_{1}),A_{2}(\theta_{2}),\dots,A_{n}(\theta_{n})}$
4. 参与者依赖于自身类型的效用函数$\displaystyle{u_{1}(a_{1},\dots,a_{n}|\theta_{1}),u_{2}(a_{1},\dots,a_{n}|\theta_{2}),\dots,u_{n}(a_{1},\dots,a_{n}|\theta_{n})}$

那么对应于完全信息静态博弈中纳什均衡的均衡--贝叶斯纳什均衡定义如下
	纯战略/混合战略贝叶斯纳什均衡是一个类型依赖的战略组合$\displaystyle{a^{*}(\theta)}$，其中参与者$\displaystyle{i}$在给定自身类型$\displaystyle{\theta_{i}}$和其他参与者类型依赖战略组合$\displaystyle{a^{*}_{-i}(\theta_{-i})}$的情况下最大化自己的期望效用函数/或者说，如果改变自己的战略，自己的效用不会增加。

举个例子：
自然决定效用矩阵为下两表，概率分别为$\displaystyle{\mu}$和$\displaystyle{1-\mu}$。

| 1\2 | L    | R    |
| --- | ---- | ---- |
| T   | 1, 1 | 0, 0 |
| B   | 0, 0 | 0, 0 |

| 1\2 | L    | R    |
| --- | ---- | ---- |
| T   | 0, 0 | 0, 0 |
| B   | 0, 0 | 2, 2 |
参与者1知道自然选择了哪张表，但参与者2不知道；参与者1和2同时行动。下面开始求解

对于参与者1，如果自然选择了上表，由于T弱优于B，因此它将会选择T战略；如果自然选择了下表，参与者1将会选择B战略

对于参与者2，由于它不知道自然选择了哪张表，因此它的期望效用矩阵如下表所示

| 1\2 | L                         | R                                  |
| --- | ------------------------- | ---------------------------------- |
| T   | $\displaystyle{\mu, \mu}$ | 0, 0                               |
| B   | 0, 0                      | $\displaystyle{2(1-\mu),2(1-\mu)}$ |

那么这样存在两个纯战略纳什均衡，即(T, L)和(B, R)。

因此，总共有两个纯战略贝叶斯纳什均衡，即参与者2选择L或者R，参与者1根据自然的选择而做出不同选择。

### 不完全信息动态博弈

(几乎没考过，看看就行)

在不完全信息动态博弈的过程中，自然首先选择参与者的类型（**先验概率**），然后参与者先后开始行动。后行动者会根据先行动者的行动修正先行动者类型的认识（**后验概率**），并以此指导自身的行动；先行动者知道后行动者会根据先行动者的行动来修正后行动者对先行动者类型的认识，就会选择传递对自己有利的信息，等等。在不完全信息动态博弈的过程中，博弈的过程不仅是参与者选择行动的过程，还是参与者根据其他参与者的行动不断**修正信念**的过程。

首先我们看后行动者如何根据先行动者的行动来修正自己的信念，也就是**如何根据新的信息用先验概率得到后验概率**，也就是**贝叶斯公式**
概率那里已经写过了，这里我们将其抄过来并解释其内涵

$$\tag{4.1}
\begin{align}
P(B_{i}|A)=\frac{P(B_{i})P(A|B_{i})}{\sum^{\infty}_{j=1}P(B_{j})P(A|B_{j})}
\end{align}
$$
其中我们将$\displaystyle{P(B_{i}|A)}$解释为先行动者行动$\displaystyle{A}$后行动者认为先行动者为类型$\displaystyle{B_{i}}$的后验概率；$\displaystyle{A}$为新的信息，即先行动者的行动；$\displaystyle{P(B_{i})}$为后行动者认为先行动者为类型$\displaystyle{B_{i}}$的先验概率，$\displaystyle{P(A|B_{i})}$为在后行动者认为先行动者为类型$\displaystyle{B_{i}}$时进行行动$\displaystyle{A}$的概率。

精炼贝叶斯均衡假定参与者根据此贝叶斯法则修正先验概率。其定义为：精炼贝叶斯均衡是一个战略组合，和一个后验概率组合，满足
1. 对于所有参与者在每一个信息集，都有其战略使得其期望效用函数最大
