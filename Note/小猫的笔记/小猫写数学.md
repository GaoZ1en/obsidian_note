### 函数、极限、连续

函数$\displaystyle{f(x)}$是一个定义在实数集到实数集上的映射
定义域，值域和函数关系，只要有一个不一样就是不同的函数

可能具有以下性质
1. 有界
2. 单调
3. 周期
	1. $\displaystyle{f(x+T)=f(x)}$，其中$\displaystyle{T}$称为周期
	2. 存在不存在最小正周期的函数，如狄利克雷函数$\displaystyle{D(x)}$
4. 奇偶
	1. $\displaystyle{f(x)=f(-x)}$，偶函数
	2. $\displaystyle{f(x)=-f(-x)}$，奇函数

两个函数$\displaystyle{f(x),g(x)}$可以通过复合得到新的函数$\displaystyle{f(g(x)),g(f(x))}$
对于一个函数$\displaystyle{f(x)}$，其反函数$\displaystyle{f^{-1}(x)}$满足$\displaystyle{f(f^{-1}(x))=x}$
分段函数就是在定义域的不同部分具有不同的定义的函数，比如$$\tag{1.1}\begin{align}\mathrm{sgn}( x )=\begin{cases}1, & x>0 \\0, & x=0 \\-1, & x<0\end{cases}\end{align}$$
隐函数指无法通过一个具体的表达式来表示的函数
比如函数$\displaystyle{f(x)}$可以通过$\displaystyle{e^{f(x)}-f(x)=x}$的方式表示，但无法解出其显式

基本初等函数
1. 常函数，$\displaystyle{f(x)=C}$
2. 幂函数，$\displaystyle{f(x)=x^{n}}$
3. 三角函数，$\displaystyle{f(x)=\sin x,\cos x,\tan x,\cot x,\sec x,\csc x}$
4. 指数函数，$\displaystyle{f(x)=e^{x}}$
5. 对数函数，$\displaystyle{f(x)=\log_{a}x}$
6. 反三角函数
初等函数即为基本初等函数的有限次四则运算与复合所得到的函数


数列极限
$\displaystyle{\forall\varepsilon>0,\exists N>0,\forall n>N,|a_{n}-a|<\varepsilon \Leftrightarrow \lim_{ n \to \infty }a_{n}=a}$
函数极限
$\displaystyle{\forall \varepsilon>0,\exists \delta>0,\forall x\in U_{0}(x_{0},\varepsilon),|f(x)-a|<\varepsilon\Leftrightarrow\lim_{ x \to x_{0} }f(x)=a}$
性质
1. 线性
2. 若$\displaystyle{\lim_{ n \to \infty }a_{n}=\lim_{ n \to \infty }c_{n}}$且$\displaystyle{\forall n>N_{0},a_{n}\leqslant b_{n}\leqslant c_{n}}$，那么$\displaystyle{\lim_{ n \to \infty }b_{n}=\lim_{ n \to \infty }a_{n}}$
3. 单调有界函数/数列必有极限

左右极限
$\displaystyle{\forall \varepsilon>0,\exists \delta>0,\forall x\in U_{\pm}(x_{0},\varepsilon)},|f(x)-a|<\varepsilon\Leftrightarrow\lim_{ x \to x_{0}^{\pm} }f(x)=a$

无穷大量和无穷小量都是**极限**
无穷小量的比较。如果两个无穷小量$\displaystyle{f(x),g(x)}$有
1. $\displaystyle{\lim_{ x \to x_{0} } \frac{f(x)}{g(x)}=0}$，那么称$\displaystyle{f(x)}$比$\displaystyle{g(x)}$更高阶无穷小
2. $\displaystyle{\lim_{ x \to x_{0} } \frac{f(x)}{g(x)}=\infty}$，那么称$\displaystyle{f(x)}$比$\displaystyle{g(x)}$更低阶无穷小
3. $\displaystyle{\lim_{ x \to x_{0} } \frac{f(x)}{g(x)}=C}$，那么称$\displaystyle{f(x)}$是$\displaystyle{g(x)}$的同阶无穷小
	1. 若$\displaystyle{C=1}$，那么称$\displaystyle{f(x)}$是$\displaystyle{g(x)}$的等价无穷小

两个重要极限
$$\tag{1.2}
\begin{align}
\lim_{ x \to \infty } \left( 1+\frac{1}{x} \right)^{x}=e \\
\lim_{ x \to 0 } \frac{\sin x}{x}=1
\end{align}
$$

函数连续，若$\displaystyle{\lim_{ x \to x_{0} }f(x)=f(x_{0})}$，那么称函数在$\displaystyle{x_{0}}$处连续
连续的性质
1. 在邻域有界
2. 连续函数的有限次四则运算也连续

不连续点可能有几种类型
1. 第一类间断点
	1. 左右极限$\displaystyle{\lim_{ x \to x_{0}^{\pm} }f(x)}$均存在
	2. 可去间断点，左右极限相等。补充定义$\displaystyle{f(x_{0})=\lim_{ x \to x_{0} }f(x)}$即可连续
	3. 跳跃间断点，左右极限不相等
2. 第二类间断点
	1. 左右极限$\displaystyle{\lim_{ x \to x_{0}^{\pm} }f(x)}$至少有一个不存在
	2. 无穷间断点，左右极限至少有一个为无穷
	3. 振荡间断点，类似于$\displaystyle{f(x)=\sin \frac{1}{x}}$在趋于$\displaystyle{x=0}$处的行为

**初等函数在其定义域上连续**

闭区间上的连续函数具有以下性质
1. 有界
2. 能够在闭区间上取到最大值和最小值
3. 介值定理：在最大值和最小值之间的值都能取到。

### 微分学

导数，一类特殊极限
若$\displaystyle{\lim_{ x \to x_{0} } \frac{f(x)-f(x_{0})}{x-x_{0}}}$存在，那么称函数$\displaystyle{f(x)}$在$\displaystyle{x_{0}}$可导

可导一定连续，连续不一定可导

平面曲线的切线方程与发现方程
设曲线由$\displaystyle{y=f(x)}$表示($\displaystyle{f(x,y)=0}$为其更一般的情况)，那么切线方程由$\displaystyle{y-f(x_{0})=f'(x_{0})(x-x_{0})}$给出，法线方程由$\displaystyle{y-f(x_{0})=-\frac{1}{f'(x_{0})}(x-x_{0})}$给出

微分$\displaystyle{\mathrm{d}f(x)=f'(x)\mathrm{d}x}$，跟导数直接相关。形式上可以将导数看作两个微分的商，因此导数也被叫做微商

微分和导数的性质
1. 线性：$\displaystyle{\frac{\mathrm{d}}{\mathrm{d}x}(a f(x)+b g(x))=a \frac{\mathrm{d}f}{\mathrm{d}x}+b \frac{\mathrm{d}f}{\mathrm{d}x}}$, $\displaystyle{\mathrm{d}(af+b g)=a\mathrm{d}f+b\mathrm{d}g}$
2. 复合函数求导，链式法则：$\displaystyle{\frac{\mathrm{d}}{\mathrm{d}x}f(g(x))= \frac{\mathrm{d}f}{\mathrm{d}g} \frac{\mathrm{d}g}{\mathrm{d}x}}$, $\displaystyle{\mathrm{d}f(g(x))=f'(g)\mathrm{d}g=f'(g)g'(x)\mathrm{d}x}$
3. 反函数的导数：$\displaystyle{y=f^{-1}(x)\implies x=f(y)\implies \frac{\mathrm{d}x}{\mathrm{d}y}=f'(y)\implies \frac{\mathrm{d}y}{\mathrm{d}x}=\frac{1}{f'(y)}}$. $\displaystyle{\mathrm{d}y=\frac{\mathrm{d}x}{f'(y)}}$
4. 乘法与除法：$\displaystyle{\frac{\mathrm{d}(uv)}{\mathrm{d}x}=\frac{\mathrm{d}u}{\mathrm{d}x}v+u\frac{\mathrm{d}v}{\mathrm{d}x},\frac{\mathrm{d}(u/v)}{\mathrm{d}x}=\frac{uv'-vu'}{u^{2}}}$

微分中值定理
1. 罗尔定理：闭区间连续开区间可导且区间两端函数值相等的函数至少存在一点使得该点导数值为零
	1. $\displaystyle{\exists \xi\in (a,b),\mathrm{s.t.} f'(\xi)=0}$
2. 拉格朗日中值定理：闭区间连续开区间可导的函数至少存在一点使得该点导数值为区间内的平均导数
	1. $\displaystyle{\exists \xi\in (a,b),\mathrm{s.t.} f'(\xi)=\frac{f(a)-f(b)}{a-b}}$
3. 柯西中值定理：闭区间连续开区间可导的两个函数至少存在一点使得该点导数值之比为区间两端函数值差的比
	1. $\displaystyle{\exists \xi\in (a,b),\mathrm{s.t.} \frac{f'(\xi)}{g'(\xi)}=\frac{f(a)-f(b)}{g(a)-g(b)}}$
4. 泰勒定理：闭区间连续开区间可导的函数可以用一个多项式逼近。
	1. $\displaystyle{f(x)=\sum^{\infty}_{n=0} \frac{f^{(n)}(x_{0})}{n!}(x-x_{0})^{n}}$
	2. 麦克劳林展开指在$\displaystyle{x=0}$处进行展开
		1. $\displaystyle{e^{x}=\sum^{\infty}_{n=0} \frac{x^{n}}{n!}=1+x+\frac{x^{2}}{2!}+\frac{x^{3}}{3!}+\dots}$
		2. $\displaystyle{\sin x=\sum^{\infty}_{n=0} \frac{(-1)^{n}}{(2n-1)!}x^{2n-1}=x-\frac{x^{3}}{6}+\dots}$
		3. $\displaystyle{\cos x=\sum^{\infty}_{n=0} \frac{(-1)^{n}}{(2n)!}x^{2n}=1-\frac{x^{2}}{2}+\dots}$
		4. $\displaystyle{\ln(1+x)=\sum^{\infty}_{n=1} \frac{(-1)^{n-1}}{n}x^{n}=x-\frac{x^{2}}{2}+\dots}$
		5. $\displaystyle{(1+x)^{\alpha}=\sum^{\infty}_{n=0} \frac{\alpha!}{n!}x^{n}=1+\alpha x+\frac{\alpha(\alpha-1)}{2}x^{2}+\frac{\alpha(\alpha-1)(\alpha-2)}{3!}x^{3}+\dots}$
			1. $\displaystyle{(1+x)^{-1}=1-x+x^{2}-x^{3}+\dots}$
			2. $\displaystyle{(1-x)^{-1}=1+x+x^{2}+x^{3}+\dots}$
泰勒展开是**最有效**的计算极限的方法，下面举例

$$\tag{1.2}
\begin{align}
 & \lim_{ x \to 0 } \frac{\sin^{3} x-2(1-\cos x)\ln(1+x)}{\tan x-\sin x} \\
= & \lim_{ x \to 0 } \frac{\left( x-\frac{x^{3}}{6}+\dots \right)^{3}-2\left( 1-\left( 1-\frac{x^{2}}{2}+\frac{x^{4}}{4!}\right) \right)\left( x-\frac{x^{2}}{2}+\frac{x^{3}}{3}+\dots \right)}{\left( x-\frac{x^{3}}{6}+\dots \right)\left( 1-1/\left( 1-\frac{x^{2}}{2}+\dots \right)\right)} \\
= & \lim_{ x \to 0 } \frac{x^{3}\left( 1-\frac{x^{2}}{6} \right)^{3}-x^{3}\left( 1-\frac{x^{2}}{12}+\dots\right)\left( 1-\frac{x}{2}+\frac{x^{2}}{3}+\dots \right)}{x\left( 1-\frac{x^{2}}{6}+\dots \right)\left( 1-\left( 1+\frac{x^{2}}{2}+\dots \right) \right)} \\
= & \lim_{ x \to 0 } \frac{x^{3}\left( 1-\frac{x^{2}}{2}+\dots \right)-x^{3}\left( 1-\frac{x}{2}+\dots \right)}{-\frac{x^{3}}{2}\left( 1-\frac{x^{2}}{2}+\dots \right)}=0
\end{align}
$$

洛必达法则相对更低效一点，并且适用性不算太广
对于不定式，即分子分母均为无穷小量或无穷大量的情况，原极限等于分子分母同时求导后再取极限。
即

### 积分学

$\displaystyle{f(x)}$的原函数$\displaystyle{F(x)}$，即其导数为$\displaystyle{f(x)}$的函数，即$\displaystyle{F'(x)=f(x)}$
不定积分，就是所有原函数的集合，写作$\displaystyle{\int f(x)\mathrm{d}x}=F(x)+C$

性质
1. 线性：$\displaystyle{\int(a f(x)+bg(x))\mathrm{d}x}=a\int f(x)\mathrm{d}x+b\int g(x)\mathrm{d}x$
2. 换元：$\displaystyle{\int f(g(x))g'(x)\mathrm{d}x\overset{u=g(x)}{=} \int f(u)\mathrm{d}u}$
3. 分部积分：$\displaystyle{\int uv'=uv-\int vu'}$

基本积分公式
1. $\displaystyle{\int e^{x}\mathrm{d}x=e^{x}+C}$
2. $\displaystyle{\int x^{\alpha}\mathrm{d}x}=\frac{x^{1+\alpha}}{1+\alpha},\alpha \not=-1$
3. $\displaystyle{\int \frac{\mathrm{d}x}{x}=\ln |x|}$
4. $\displaystyle{\int \sin x\mathrm{d}x=-\cos x+C}$
5. $\displaystyle{\int \cos x\mathrm{d}x=\sin x+C}$
6. $\displaystyle{\int \frac{\mathrm{d}x}{\sqrt{ a^{2}-x^{2} }}=\arcsin \frac{x}{a}+C}$
7. $\displaystyle{\int \frac{\mathrm{d}x}{a^{2}+x^{2}}=\frac{1}{a}\arctan \frac{x}{a}+C}$
8. $\displaystyle{\int \frac{\mathrm{d}x}{\sqrt{ x^{2}\pm a^{2} }}=\ln(x+\sqrt{ x^{2}\pm a^{2} })+C}$

定积分就是曲线与x轴相夹的曲边梯形的面积，计算它可以由牛顿-莱布尼茨公式进行计算
$$\tag{1.4}
\begin{align}
\int^{b}_{a}f(x)\mathrm{d}x=F(b)-F(a)
\end{align}
$$
其中$\displaystyle{F(x)}$为$\displaystyle{f(x)}$的原函数

同时我们可以利用定积分的定义计算一类特殊的极限
$$\tag{1.5}
\begin{align}
\lim_{ n \to \infty } \sum^{n}_{i=1} \frac{1}{n}f\left( \frac{x}{n} \right)=\int^{1}_{0}f(x)\mathrm{d}x
\end{align}
$$
需要灵活的使用。

对于变限积分$\displaystyle{\int^{g(x)}_{h(x)}f(x)\mathrm{d}x}$，可以求其导数

$$\tag{1.6}
\begin{align}
\frac{\mathrm{d}}{\mathrm{d}x}\int^{g(x)}_{h(x)}f(x,t)\mathrm{d}t=\int^{g(x)}_{h(x)}f'(x,t)\mathrm{d}t+f(x,t)(g'(x)-h'(x))
\end{align}
$$

反常积分，即积分上下限为无穷或函数值为无穷的点（称为瑕点）的定积分，其定义实际上就是积分限推向无穷或瑕点的极限。
首先我们引入两个基本的积分：

$$\tag{1.7}
\begin{align}
\int^{+\infty}_{a>0}x^{\alpha}\mathrm{d}x  & =\frac{a^{1+\alpha}}{1+\alpha},\quad\alpha<-1\\
\int^{a}_{0}x^{\alpha}\mathrm{d}x & =\frac{a^{1+\alpha}}{1+\alpha},\quad \alpha>-1
\end{align}
$$

判断反常积分收敛（也就是极限存在）
比较判别法是最常用的方法。即：
设$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$为待判定收敛积分，设$\displaystyle{\int^{\infty}_{a}g(x)\mathrm{d}x}$收敛，那么如果
1. $\displaystyle{f(x)\leqslant g(x)}$，那么$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$也收敛
2. $\displaystyle{\lim_{ x \to \infty } \frac{f(x)}{g(x)}=a}$
	1. $\displaystyle{|a|\leqslant \infty}$，那么$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$也收敛
设$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$为待判定收敛积分，设$\displaystyle{\int^{\infty}_{a}g(x)\mathrm{d}x}$发散，那么如果
1. $\displaystyle{f(x)\geqslant g(x)}$，那么$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$也发散
2. $\displaystyle{\lim_{ x \to \infty } \frac{f(x)}{g(x)}=a}$
	1. $\displaystyle{a\not=0}$，那么$\displaystyle{\int^{\infty}_{a}f(x)\mathrm{d}x}$也发散

如果能直接积分，直接积分也是一种方法。

### 多元函数

多元函数，就是从$\displaystyle{\mathbb{R}^{n}}$的子集$\displaystyle{U}$到$\displaystyle{\mathbb{R}}$的映射

一元函数极限、连续、导数和积分的推广如下：

极限：$\displaystyle{\forall \varepsilon>0,\exists \delta>0,\forall(x,y)\in U_{0}((x_{0},y_{0}),\varepsilon),|f(x,y)-A|<\varepsilon}$，记作$\displaystyle{\lim_{ (x,y) \to (x_{0},y_{0}) }f(x,y)=A}$
注意只要有一条路径使得A不唯一，那么极限就不存在

连续，与一元函数相同，$\displaystyle{\lim_{ (x,y) \to (x_{0},y_{0}) }f(x,y)=f(x_{0},y_{0})}$。
具有以下定理
1. 闭域上的连续函数能够取到最大值和最小值，以及它们之间的所有值

偏导数。$\displaystyle{f'_{x}(x,y)=\lim_{ \Delta x \to 0 } \frac{f(x_{0}+\Delta x,y_{0})-f(x_{0},y_{0})}{\Delta x},f'_{y}(x,y)=\lim_{ \Delta y \to 0 }(\frac{f(x_{0}),y_{0}+\Delta h)-f(x_{0},y_{0})}{\Delta y}}$
高阶偏导数，求多次偏导数即可得到。对于$\displaystyle{n+1}$阶偏导数连续的函数$\displaystyle{f(x,y)}$，其所有$\displaystyle{n}$阶混合偏导数都相等（问一句小猫这是什么意思）

全微分，$\displaystyle{\mathrm{d}f(x,y)=f_{x}'(x,y)\mathrm{d}x+f'_{y}(x,y)\mathrm{d}y}$。
使用全微分可以得到链式法则：
$$\tag{1.8}
\begin{align}
\mathrm{d}f(g(x,y),h(x,y)) & =f'_{u}(u,v)\mathrm{d}u+f'_{v}(u,v)\mathrm{d}v \\
 & =f'_{u}(g(x,y),h(x,y))(g'_{x}(x,y)\mathrm{d}x+g_{y}'(x,y)\mathrm{d}y)+f'_{v}(g(x,y),h(x,y)(h'_{x}(x,y)\mathrm{d}x+h'_{y}(x,y)\mathrm{d}y) \\
 & =(f'_{u}(g(x,y),h(x,y))g'_{x}(x,y)+f'_{v}(g(x,y),h(x,y))h'_{x}(x,y))\mathrm{d}x \\
 & +(f'_{v}(g(x,y),h(x,y))h'_{y}(x,y)+f'_{v}(g(x,y),h(x,y))h'_{y}(x,y))\mathrm{d}y \\
\implies \frac{\partial}{\partial x}f(g(x,y),h(x,y)) & =f'_{u}(g(x,y),h(x,y))g'_{x}(x,y)+f'_{v}(g(x,y),h(x,y))h'_{x}(x,y) \\
\frac{\partial}{\partial y}f(g(x,y),h(x,y)) & =f'_{u}(g(x,y),h(x,y))g'_{y}(x,y)+f'_{v}(g(x,y),h(x,y))h'_{y}(x,y)
\end{align}
$$

这里问小猫

多元函数的极值需要令所有偏导数为0得到驻点，然后再求二阶导数$\displaystyle{f''_{x x}f''_{y y}}-f_{x y}^{''2}$在驻点处的符号。
1. 如果$\displaystyle{f''_{x x}f''_{y y}}-f_{x y}^{''2}>0$，那么会得到极小值
2. 如果$\displaystyle{f''_{x x}f''_{y y}}-f_{x y}^{''2} <0$，那么会得到极大值
3. 如果$\displaystyle{f''_{x x}f''_{y y}}-f_{x y}^{''2}=0$，那么没有办法判断

如果要求$\displaystyle{f(x,y)}$在约束条件$\displaystyle{g(x,y)}$下的极值，需要像下面这么做

定义$\displaystyle{L(x,y,\lambda)=f(x,y)+\lambda g(x,y)}$，并令三个偏导数等于0

$$\tag{1.10}
\begin{align}
\frac{\partial L}{\partial x} & =f'_{x}(x,y)+\lambda g'_{x}(x,y)=0 \\
\frac{\partial L}{\partial y} & =f'_{y}(x,y)+\lambda g'_{y}(x,y)=0 \\
\frac{\partial L}{\partial \lambda} & =g(x,y)=0
\end{align}
$$

求解的时候首先用前两个式子消去$\displaystyle{\lambda}$，然后将所得代入第三个式子，最后解出来即可。

二重积分的定义类似于一元函数的定积分。具有以下性质
1. 线性
2. $\displaystyle{f(x)\geqslant g(x)}$, $\displaystyle{\int_{D}f(x)\mathrm{d}x\mathrm{d}y\geqslant\int_{D}g(x)\mathrm{d}x\mathrm{d}y}$

### 无穷级数

级数就是无穷求和$\displaystyle{\sum^{\infty}_{n=0}a_{n}}$，收敛指极限存在。
绝对收敛，指$\displaystyle{\sum^{\infty}_{n=0}|a_{n}|}$也收敛的级数，否则称为条件收敛

**常数项级数**
首先引入一个特定的收敛级数

$$\tag{1.11}
\begin{align}
\sum^{\infty}_{n=1}n^{\alpha},\alpha<-1
\end{align}
$$
然后给出若干收敛判别法
1. 若$\displaystyle{\lim_{ n \to \infty } |\frac{a_{n+1}}{a_{n}}|=q}$
	1. $\displaystyle{q\geqslant1}$级数不收敛
	2. $\displaystyle{q<1}$级数收敛
2. 若$\displaystyle{\lim_{ n \to \infty }\sqrt[n]{ a_{n} }=q}$
	1. $\displaystyle{q\geqslant 1}$级数发散
	2. $\displaystyle{q<1}$级数收敛
3. 比较判别。设$\displaystyle{\sum^{\infty}_{n=0}b_{n}}$，且$\displaystyle{\lim_{ n \to \infty } |\frac{a_{n}}{b_{n}}|=q}$
	1. $\displaystyle{q> 0}$，$\displaystyle{\sum^{\infty}_{n=0}a_{n}}$与$\displaystyle{\sum^{\infty}_{n=0}b_{n}}$同发散
	2. $\displaystyle{q< +\infty}$，$\displaystyle{\sum^{\infty}_{n=0}a_{n}}$与$\displaystyle{\sum^{\infty}_{n=0}b_{n}}$同收敛
4. 考虑积分$\displaystyle{\int^{\infty}_{1}a(x)\mathrm{d}x}$，$\displaystyle{\sum^{\infty}_{n=1}a_{n}}$与其同敛散

幂级数，指形式类似于$\displaystyle{\sum^{\infty}_{n=0}a_{n}(x-a)^{n}}$的级数

$$

### 微分方程

微分方程即求解为未知函数$\displaystyle{y(x)}$，且包含其各阶导数的方程$\displaystyle{f(x,y(x),y'(x),\dots)=0}$，以及若干边界条件$\displaystyle{y(x_{0})=y_{0},y'(x_{1})=y'_{0},\dots}$
方程含有最高阶导数的阶数就称为方程的阶，设方程的阶为$\displaystyle{n}$，那么方程的**通解**含有一定会有$\displaystyle{n}$个未定参数$\displaystyle{C_{1},\dots,C_{n}}$，此时需要用边界条件对这些未定条件进行确定，得到一个**特解**。
有时候有的解不在通解里，事实上这些解是通解的**包络**

**变量可分离的微分方程**，即可以转化为以下形式的微分方程
$$\tag{1.13}
\begin{align}
f(y)\mathrm{d}y=g(x)\mathrm{d}x
\end{align}
$$
这样两边分别积分：
$$\tag{1.14}
\begin{align}
\int f(y)\mathrm{d}y=\int g(x)\mathrm{d}x+C
\end{align}
$$
即可得到通解

**齐次微分方程**，即具有形式$\displaystyle{y'}=f\left( \frac{y}{x} \right)$的方程，只需要做替换$\displaystyle{u=\frac{y}{x}}$即可转化为变量可分离的微分方程

一阶线性微分方程，即具有形式$\displaystyle{y'+f(x)y=g(x)}$的方程
方程的通解为

$$\tag{.}
\begin{align}
y=\left( C+g(x)e^{\int f(x)\mathrm{d}x} \right)e^{-\int f(x)\mathrm{d}x}
\end{align}
$$

**线性微分方程**，即在方程的每一项中都只含有一个未知函数的微分方程
对于$\displaystyle{n}$阶微分方程，解为$\displaystyle{n}$个基本解的线性组合$\displaystyle{a_{1}y_{1}+a_{2}y_{2}+\dots+a_{n}y_{n}}$再加上一个特解$\displaystyle{y^{*}}$

对于二阶常系数线性微分方程$\displaystyle{y''+2\beta y'+\gamma y=f(x)}$，解的方法如下：

首先考虑对应的齐次方程$\displaystyle{y''+2\beta y'+\gamma y=0}$，给出其本征方程$\displaystyle{\lambda^{2}+2\beta \lambda+\gamma=0\implies \lambda_{1,2}=-\beta\pm \sqrt{ \beta^{2}-\gamma }}$
1. 若$\displaystyle{\beta^{2}>\gamma}$，那么齐次方程的通解为$\displaystyle{y=\alpha_{1} e^{-\beta x}\cosh \sqrt{ \beta^{2}-\gamma }x+\alpha_{2}e^{-\beta x}\sinh \sqrt{ \beta^{2}-\gamma }x}$
2. 若$\displaystyle{\beta^{2}=\gamma}$，那么齐次方程的通解为$\displaystyle{y=\alpha_{1} e^{-\beta x}+\alpha_{2}xe^{-\beta x}}$
3. 若$\displaystyle{\beta^{2}<\gamma}$，那么齐次方程的通解为$\displaystyle{y=\alpha_{1} e^{-\beta x}\cos \sqrt{ \gamma-\beta^{2} }x+\alpha_{2}e^{-\beta x}\sin \sqrt{ \gamma-\beta^{2}}x}$
然后再给出一个非齐次方程的特解
1. $\displaystyle{f(x)}=P_{n}(x)$，设$\displaystyle{y^{*}(x)=Q_{n}(x)}$，待定系数并代入解出$\displaystyle{Q_{n}(x)}$
2. $\displaystyle{f(x)=P_{n}(x)e^{-\xi x}}$，设$\displaystyle{y^{*}(x)=Q_{n}(x)e^{-\xi x}}$
3. $\displaystyle{f(x)=P_{n}(x)\sin x}+Q_{m}(x)\cos x$，设$\displaystyle{y^{*}(x)=R_{M}(x)\sin x+S_{M}(x)\cos x}$，其中$\displaystyle{M=max(m,n)}$

## 概率论与统计学

**样本空间**：随机现象所有可能出现的基本结果组成的集合，
**样本点**：构成样本空间的基本结果
**随机事件**：样本点构成的集合

**Venn图**：图形化表示随机事件，随机事件计算的利器。其中最大的图形表示为样本空间，其中的点为样本点，其他图形可以表示随机事件。
**随机变量**：一种函数

**事件间的关系**：
1. 包含。若属于随机事件$\displaystyle{A}$的样本点必定属于随机事件$\displaystyle{B}$，则称$\displaystyle{A}$属于$\displaystyle{B}$，记为$\displaystyle{A\subset B}$或$\displaystyle{B\supset A}$
2. 相等，若$\displaystyle{A\subset B}$且$\displaystyle{B\subset A}$
3. 互不相容，若$\displaystyle{A\not\subset B}$且$\displaystyle{B\not\subset A}$
然而这并不包括所有的关系。因此我们引入事件间的运算

**事件间的运算**
1. 并。$\displaystyle{A\cup B=\left\{x\in\Omega|x\in A \text{或} x\in B\right\}}$
2. 交。$\displaystyle{A\cap B=\left\{x\in \Omega|x\in A,x\in B\right\}}$
3. 差。$\displaystyle{A-B=\left\{x\in \Omega|x\in A,x\not\in B\right\}}$
可以用Venn图方便的进行计算，必须掌握

对立事件
$\displaystyle{\bar{A}=\Omega-A}$

**运算性质**
1. 交换律：$\displaystyle{A\cup B=B\cup A,A\cap B=B\cap A}$
2. 结合律：$\displaystyle{(A\cup B)\cup C=A\cup(B\cup C),(A\cap B)\cap C=A\cap(B\cap C)}$
3. 分配律：$\displaystyle{(A\cap B)\cup C=(A\cup C)\cap(B\cup C), (A\cup B)\cap C=(A\cap C)\cup(B\cap C)}$
4. de Morgan：$\displaystyle{\overline{A\cup B}=\bar{A}\cap \bar{B}, \overline{A\cap B}=\bar{A}\cup \bar{B}}$
依然可以用Venn图简单地进行证明

**排列组合公式与古典概型**
1. 乘法原理
	1. 如果某件事需要$\displaystyle{k}$步才能完成，其中第$\displaystyle{i}$步有$\displaystyle{m_{i}}$种方法完成，那么总共有$\displaystyle{\prod^{k}_{i=1}m_{i}}$种方法
2. 加法原理
	1. 如果某件事有$\displaystyle{k}$种途径完成，其中第$\displaystyle{i}$种途径有$\displaystyle{m_{i}}$种方法，那么总共有$\displaystyle{\sum^{k}_{i=1}m_{i}}$种方法

1. 从$\displaystyle{n}$个中**不放回地**选出$\displaystyle{k}$个排成一排，考虑顺序
	1. $\displaystyle{A^{k}_{n}=\frac{n!}{(n-k)!}}$
2. 从$\displaystyle{n}$个中**不放回地**选出$\displaystyle{k}$个分成一组，不考虑顺序
	1. $\displaystyle{C_{n}^{k}=\frac{n!}{k!(n-k)!}}$

1. 从$\displaystyle{n}$个中**有放回地**依次选出$\displaystyle{k}$个排成一排，考虑顺序
	1. $\displaystyle{n^{k}}$
2. 从$\displaystyle{n}$个中**有放回地**依次选出$\displaystyle{k}$个分成一组，不考虑顺序
	1. $\displaystyle{C_{n+r-1}^{r}}$

**古典概型**指具有有限样本点，且所有样本点的概率都相等的概率模型。可以使用上面所提及的乘法原理和加法原理，以及排列组合数来进行计算

古典概型举例
1. $\displaystyle{N}$个产品中有$\displaystyle{M}$个次品，从中不放回地随机选出$\displaystyle{n}$个产品，其中有$\displaystyle{m}$个次品的概率为$\displaystyle{P_{N,M,n,m}= \frac{C_{M}^{n}C_{N-M}^{n-m}}{C_{N}^{n}}}$

**几何概型**指样本空间充满某个区域，且单位度量子区域的概率相等的概率模型。$\displaystyle{P(A)=\frac{S_{A}}{S_{\Omega}}}$

**概率的性质**
1. $\displaystyle{P(\Omega)=1,P(\emptyset)=0}$
2. 可加性：若$\displaystyle{A_{1},A_{2},\dots,A_{n},\dots}$互不相容，那么$\displaystyle{P\left(\bigcup^{\infty}_{i=1}A_{i}\right)=\sum^{\infty}_{i=1}P(A_{i})}$
	1. $\displaystyle{P(\bar{A})=1-P(A)}$
3. 单调性：$\displaystyle{A\subset B\implies P(A)\leqslant P(B)}$
4. 加法公式：$\displaystyle{P(A\cup B)=P(A)+P(B)-P(A\cap B)}$

**条件概率**：指在某事件$\displaystyle{B}$发生的前提下，事件$\displaystyle{A}$发生的概率，记为$\displaystyle{P(A|B)}$
计算公式：$\displaystyle{P(A|B)=\frac{P(A\cap B)}{P(B)}}$
性质：
1. $\displaystyle{P(A|B)\geqslant 0}$
2. $\displaystyle{P(\Omega|B)=1}$
3. 若$\displaystyle{A_{1},A_{2},\dots,A_{n},\dots}$互不相容，那么$\displaystyle{P\left( \bigcup^{\infty}_{i=1}A_{i}|B \right)=\sum^{\infty}_{i=1}P(A_{i}|B)}$
4. $\displaystyle{P(A\cap B)=P(B)P(A|B)}$
	1. $\displaystyle{P(A_{1}\cap\dots \cap A_{n})=P(A_{1})P(A_{2}|A_{1})\dots P(A_{n}|A_{1}\cap\dots \cap A_{n-1})}$
5. 若$\displaystyle{B_{1},B_{2},\dots,B_{n},\dots}$互不相容且$\displaystyle{\bigcup^{\infty}_{i=1}B_{i}=\Omega}$，那么$\displaystyle{P(A)=\sum^{n}_{i=1}P(B_{i})P(A|B_{i})}$
	1. $\displaystyle{P(A)=P(B)P(A|B)+P(\bar{B})P(A|\bar{B})}$
	2. 反过来，$\displaystyle{P(B_{i}|A)=\frac{P(B_{i})P(A|B_{i})}{\sum^{\infty}_{j=1}P(B_{j})P(A|B_{j})}}$

**独立**：两事件$\displaystyle{A,B}$独立指$\displaystyle{P(A\cap B)=P(A)P(B)}$来；多个事件相互独立指其中任意两个事件都相互独立

**随机变量**：样本点的实值函数，通常用$\displaystyle{X,Y,Z}$表示
**分布函数**：$\displaystyle{F(x)=P\left(X\leqslant x\right)}$
性质：
1. 单调非减
2. 有界
3. 右连续

对于离散随机变量（取值范围为有限或可列的值），分布函数是分段函数，不方便。通常用**概率分布列**来表示离散随机变量的概率分布
**概率分布列**：对于离散随机变量$\displaystyle{X}$，设其可能的取值为$\displaystyle{x_{1},x_{2},\dots ,x_{n},\dots}$，那么称$\displaystyle{p_{i}=P(X=x_{i})}$为$\displaystyle{X}$的概率分布列
*注意需要将所有的*$\displaystyle{p_{i}}$*都列出来*，*或者给出他们的通式*。
性质
1. 非负：$\displaystyle{p_{i}\geqslant 0}$
2. 正则：$\displaystyle{\sum^{\infty}_{i=1}p_{i}=1}$
3. $\displaystyle{F(x)=\sum_{x_{n}\leqslant x}p_{n}}$

对于连续随机变量，对应于概率分布列的概念为**概率密度函数**，记为$\displaystyle{\rho(x)}$
其概率含义为，$\displaystyle{P(x<X<x+\mathrm{d}x)}=\rho(x)\mathrm{d}x$
性质
1. 非负：$\displaystyle{\rho(x)\geqslant 0}$
2. 正则：$\displaystyle{\int^{\infty}_{-\infty}\rho(x)\mathrm{d}x=1}$
3. $\displaystyle{F(x)=\int^{x}_{-\infty}\rho(x)\mathrm{d}x}$
可以看到与概率分布列一一对应

**数学期望**：
1. 对于离散随机变量：$\displaystyle{E(X)=\sum^{\infty}_{i=1}x_{i}p_{i}}$
2. 对于连续随机变量：$\displaystyle{E(X)=\int^{\infty}_{-\infty}x\rho(x)\mathrm{d}x}$
性质：
1. $\displaystyle{g(X)}$的数学期望
	1. $\displaystyle{E(g(X))=\sum^{\infty}_{i=1}g(x_{i})p_{i}}$，对于离散随机变量
	2. $\displaystyle{E(g(X))=\int^{\infty}_{-\infty}g(X)\rho(x)\mathrm{d}x}$，对于连续随机变量
2. 线性：$\displaystyle{E(a f(X)+bg(X))=aE(f(X))+bE(g(X))}$
	1. $\displaystyle{E(c)=c}$

**方差和标准差**
方差定义为$\displaystyle{D(X)=E[(X-E(X))^{2}]=E(X^{2})-E(X)^{2}}$，标准差为方差的算术平方根
性质
1. 切比雪夫不等式：$\displaystyle{P(|X-E(X)|\geqslant \varepsilon)\leqslant \frac{D(X)}{\varepsilon^{2}}}$
2. 若$\displaystyle{D(X)}=0$，那么$\displaystyle{P(X=a)=1}$，但这不代表$\displaystyle{X}$不能取$\displaystyle{a}$以外的其他值
3. $\displaystyle{D(aX)=a^{2}D(X)}$
4. $\displaystyle{D(X+Y)=D(X)+D(Y)+2\mathrm{Cov}(X,Y)}$

**常见的离散概率分布**，这里给出对应的代表符号、概率分布列、数学期望、方差及某些特殊情况
1. 二项分布
	1. $\displaystyle{X\sim b(n,p)}$
	2. $\displaystyle{p_{k}=C_{n}^{k}}p^{k}(1-p)^{n-k},k=0,1,\dots,n$
	3. $\displaystyle{E(X)=\sum^{n}_{k=0}kC_{n}^{k}p^{k}(1-p)^{n-k}=np}$
	4. $\displaystyle{D(X)=E(X^{2})-E(X)^{2}=np(1-p)}$
	5. 两点分布或伯努利分布为其特殊情况$\displaystyle{b(1,p)}$

	1. 单位时间发生$\displaystyle{\lambda}$次相互独立事件，我们会用泊松分布描述

	3. $\displaystyle{p_{k}=\frac{\lambda^{k}}{k!}e^{-\lambda},k=0,1,\dots}$
	4. $\displaystyle{E(X)=\lambda}$
	5. $\displaystyle{D(X)=\lambda}$
	6. 注意$\displaystyle{E(X)=D(X)}$
3. 超几何分布，只需了解
	1. $\displaystyle{N}$个产品中有$\displaystyle{M}$个次品，从中不放回地随机选出$\displaystyle{n}$个产品，其中有$\displaystyle{m}$个次品的概率为$\displaystyle{P_{N,M,n,m}= \frac{C_{M}^{n}C_{N-M}^{n-m}}{C_{N}^{n}}}$。记$\displaystyle{X}$为有$\displaystyle{m}$个次品的概率，那么$\displaystyle{X}$服从超几何分布，记作$\displaystyle{X\sim h(n,N,M)}$

	3. $\displaystyle{E(X)=\frac{nM}{N}}$

	1. 在伯努利试验序列中，设$\displaystyle{A}$事件发生的概率为$\displaystyle{p}$，$\displaystyle{X}$为事件$\displaystyle{A}$首次发生时的试验次数，那么$\displaystyle{X}$服从几何分布，记作$\displaystyle{X\sim Ge(p)}$
	2. $\displaystyle{p_{k}=(1-p)^{k-1}p}$
		1. $\displaystyle{P(X>m+n|X>m)=P(X>n)}$这被称为**无记忆性**
	3. $\displaystyle{E(X)=\frac{1}{p}}$
	4. $\displaystyle{D(X)=\frac{1-p}{p^{2}}}$
5. 负二项分布
	1. 在伯努利试验序列中，设$\displaystyle{A}$事件发生的概率为$\displaystyle{p}$，$\displaystyle{X}$为事件$\displaystyle{A}$第$\displaystyle{r}$次发生时的试验次数，那么$\displaystyle{X}$服从负二项分布，记作$\displaystyle{X\sim Nb(r,p)}$
	2. $\displaystyle{p_{k}=C_{k-1}^{r-1}p^{r}(1-p)^{k-r}}$
	3. $\displaystyle{E(X)=\frac{r}{p}}$
	4. $\displaystyle{E(X)=\frac{r(1-p)}{p^{2}}}$
	5. 负二项分布可以分解为$\displaystyle{r}$个独立同分布的几何分布之和，即设$\displaystyle{X=X_{1}+X_{2}+\dots +X_{r},X_{i}\sim Ge(p), i=1,2,\dots,r}$，那么$\displaystyle{X\sim Nb(r,p)}$
6. 要求
	1. 对于二项分布、几何分布和负二项分布，需要会推导概率分布列$\displaystyle{p_{k}}$，数学期望和方差
	2. 需要记住二项分布、泊松分布的概率分布列，数学期望和方差
	3. 超几何分布、几何分布以及负二项分布了解即可

**随机变量函数的分布**
给定随机变量$\displaystyle{X}$，及其概率分布列/密度函数，计算$\displaystyle{Y=g(X)}$的概率分布

**总体的原则**：计算分布函数$\displaystyle{F_{Y}(y)=P(Y<y)=P(g(X)<y)}$

1. 求$\displaystyle{Z=g(X)}$的概率分布
	1. $\displaystyle{Z}$是离散随机变量
		1. 列出可能的取值，并一一计算对应的概率
	2. $\displaystyle{Z}$是连续随机变量
		1. 若$\displaystyle{g(x)}$单调增，那么 $$\tag{3.1}\begin{align}p_{Y}(y) & =\begin{cases}p_{X}(g^{-1}(y))|{g^{-1}}'(z)|, & a<z<b \\0, & \mathrm{otherwise}\end{cases}\end{align}$$，其中$\displaystyle{a=\min\left\{g(-\infty),g(+\infty)\right\},b=max\left\{g(-\infty),g(+\infty))\right\}}$
		2. 对于其他情况，总有$\displaystyle{F_{Y}(y)=P(g(x)<y)=\int_{g(x)<y}p_{X}(x)\mathrm{d}x,p_{Y}(y)=F'_{Y}(y)}$，或者可以直接利用分布函数进行计算
	3. 几个例子
		1. $\displaystyle{X\sim N(\mu,\sigma^{2}), Y=aX+b\sim N(a\mu+b,a^{2}\sigma^{2})}$
		2. $\displaystyle{X\sim Ga(\alpha,\lambda), Y=kX\sim Ga\left( \alpha, \frac{\lambda}{k} \right)}$

**分布的其他特征**
1. $\displaystyle{k}$阶矩
	1. $\displaystyle{\mu_{k}=E(X^{k})}$，中心矩$\displaystyle{\nu_{k}=E(X-E(X))^{k}}$
	2. $\displaystyle{\nu_{k}=E(X-\mu_{1})^{k}=\sum^{k}_{i=0}C_{k}^{i}\mu_{i}(-\mu_{1})^{k-i}}$
2. 变异系数
	1. 定义为标准差比数学期望，对应于分布波动。数值越大波动越大
	2. $\displaystyle{C_{v}(X)= \frac{\sqrt{ D(X) }}{E(X)}}$
3. 分位数
	1. 对于$\displaystyle{p\in (0,1)}$，称满足$\displaystyle{F(x_{p})=p}$的$\displaystyle{x_{p}}$称为分布的$\displaystyle{p}$分位数
	2. 同样可以定义上侧分位数，即满足$\displaystyle{1-F(x_{p})=p}$的$\displaystyle{x_{p}}$。
	3. 中位数即为1/2分位数
4. 偏度系数
	1. 与三阶矩有关，这个不用管了
5. 峰度系数
	1. 与四阶矩有关，也不用管了

**多维随机变量**：多个定义在统一样本空间上的随机变量的集合，写成$\displaystyle{X=(X_{1},X_{2},\dots,X_{n})}$
**联合分布函数**：$\displaystyle{F(x_{1},\dots,x_{n})=P(X_{1}\leqslant x_{1},\dots,X_{n}\leqslant x_{n})}$

对于离散随机变量，**联合分布列**为一维随机变量的概率分布列的直接推广：$\displaystyle{p_{ij}=P(X=x_{i},Y=y_{j}),i,j=1,2,\dots}$
性质
1. 非负：$\displaystyle{p_{ij}\geqslant_{0}}$
2. 正则：$\displaystyle{\sum^{\infty}_{i,j=1}p_{ij}=1}$

对于连续随机变量，**联合密度函数**为概率密度函数的推广，且对应于联合分布列：$\displaystyle{p(x,y)=\frac{\partial^{2}F}{\partial x\partial y}}$
反过来$\displaystyle{F(x,y)=\int^{x}_{-\infty}\mathrm{d}x \int^{y}_{-\infty}\mathrm{d}yp(x,y)}$
以及，$\displaystyle{P((X,Y)\in G)=\int_{G}p(x,y)\mathrm{d}x\mathrm{d}y}$

重要的分布
1. 二元正态分布
	1. $\displaystyle{(X,Y)\sim N(\mu_{1},\mu_{2},\sigma_{1}^{2},\sigma_{2}^{2},\rho)}$
	2. $\displaystyle{p(x,y)=\frac{1}{2\pi \sigma_{1}\sigma_{2}\sqrt{ 1-\rho^{2} }}\exp\left(-\frac{1}{2(1-\rho^{2})}\left[\frac{(x-\mu_{1})^{2}}{\sigma_{1}^{2}}+\frac{(y-\mu_{2})^{2}}{\sigma_{2}^{2}}-\frac{2\rho (x-\mu_{1})(y-\mu_{2})}{\sigma_{1}\sigma_{2}}\right]\right)}$

**边际（边缘）分布**
1. **边际分布函数**：$\displaystyle{X}$的边际分布函数定义为$\displaystyle{F_{X}(x)=\lim_{ y \to +\infty }F(x,y)}$，类似地也可以定义$\displaystyle{Y}$的边际分布$\displaystyle{F_{Y}(y)}$
2. 
	1. **边际分布列**：$\displaystyle{X}$的边际分布列定义为$\displaystyle{p_{i}=\sum^{\infty}_{j=1}p_{ij}}$，类似地也可以定义$\displaystyle{Y}$的边际分布列
	2. **边际概率密度**：$\displaystyle{X}$的边际概率密度定义为$\displaystyle{p_{X}(x)=\int^{\infty}_{-\infty}p(x,y)\mathrm{d}y}$，类似地也可以定义$\displaystyle{Y}$的边际概率密度

使用边际分布的概念就可以定义随机变量之间的独立
1. 设$\displaystyle{n}$维随机变量$\displaystyle{(X_{1},X_{2},\dots,X_{n})}$的联合分布函数为$\displaystyle{F(x_{1},x_{2},\dots,x_{n})}$，$\displaystyle{F_{i}(x_{i})}$为$\displaystyle{X_{i}}$的边际分布函数。若$\displaystyle{F(x_{1},x_{2},\dots,x_{n})=\prod^{n}_{i=1}F_{i}(x_{i})}$，那么称$\displaystyle{X_{1},X_{2},\dots,X_{n}}$相互独立

**随机变量函数的分布**
给定多维随机变量$\displaystyle{(X_{1},X_{2},\dots,X_{n})}$，求$\displaystyle{Y=g(X_{1},X_{2},\dots,X_{n}）}$的概率分布

**总的原则**：$\displaystyle{F(y)=P(Y\leqslant y)=P(g(X_{1},X_{2},\dots,X_{n})\leqslant y)}$, 概率分布列和概率密度可根据概率分布函数给出

1. 若$\displaystyle{Y}$为离散随机变量
	1. 将所有可能的取值列出，并一一求其概率
2. 若$\displaystyle{Y}$是连续随机变量
	1. $\displaystyle{Z=X+Y}$
		1. $\displaystyle{F_{Z}(z)=P(X+Y<z)=\int_{x+y<z}p_{X}(x)p_{Y}(y)\mathrm{d}x\mathrm{d}y,p_{Z}(z)=\int^{\infty}_{-\infty}p_{X}(x)p_{Y}(z-x)\mathrm{d}x}$
		2. 若$\displaystyle{X_{1}\sim N(\mu_{1},\sigma_{1}^{2})},X_{2}\sim N(\mu_{2},\sigma_{2}^{2})$，那么$\displaystyle{X_{1}+X_{2}\sim N(\mu_{1}+\mu_{2},\sigma_{1}^{2}+\sigma_{2}^{2})}$
	2. $\displaystyle{Z=X-Y}$
		1. 把$\displaystyle{Z=X+Y}$中$\displaystyle{Y}$换为$\displaystyle{-Y}$即可
	3. $\displaystyle{Z=XY}$
		1. $\displaystyle{F_{Z}(z)=P(XY<z)=\int_{xy<z}}p_{X}(x)p_{Y}(y)\mathrm{d}x\mathrm{d}y,p_{Z}(z)=\int^{\infty}_{-\infty}p_{X}\left( \frac{u}{v}\right)p_{Y}(v) \frac{\mathrm{d}v}{|v|}$
	4. $\displaystyle{Z=\frac{X}{Y}}$
		1. $\displaystyle{F_{Z}(z)=P\left( \frac{X}{Y}<z \right)=\int_{\frac{x}{y}<z}\rho_{X}(x)\rho_{Y}(y)\mathrm{d}x\mathrm{d}y},p_{Z}(z)=\int^{\infty}_{-\infty}p_{X}(uv)p_{Y}(v)|v|\mathrm{d}v$
	5. 要求
		1. $\displaystyle{Z=X+Y}$、$\displaystyle{Z=XY}$和$\displaystyle{Z=\frac{X}{Y}}$的情况需要背下来

**数学期望**：$\displaystyle{E(Z)=E(g(X,Y))=\int^{\infty}_{-\infty}\mathrm{d}x \int^{\infty}_{-\infty}\mathrm{d}yg(x,y)p(x,y)}$
1. 性质
	1. 线性$\displaystyle{E(aX+bY)=aE(X)+bE(Y)}$
	2. 若$\displaystyle{X,Y}$相互独立，有$\displaystyle{E(XY)=E(X)E(Y)}$
		1. 若$\displaystyle{X,Y}$相互独立，有$\displaystyle{D(X\pm Y)=D(X)+ D(Y)}$
			1. 更一般地有，$\displaystyle{D(X\pm Y)=D(X)+D(Y)\pm 2\mathrm{Cov}(X,Y)}$，其中**协方差**$\displaystyle{\mathrm{Cov}(X,Y)=E[(X-\bar{X})(Y-\bar{Y})]=E(XY)-E(X)E(Y)}$

**相关系数**：$\displaystyle{r(X,Y)=\frac{\mathrm{Cov}(X,Y)}{\sqrt{ D(X)D(Y) }}}$
1. 二维正态分布$\displaystyle{N(\mu_{1},\mu_{2},\sigma_{1}^{2},\sigma_{2}^{2},\rho)}$的相关系数即为$\displaystyle{\rho}$
2. $\displaystyle{|\mathrm{Cov}(X,Y)|^{2}\leqslant D(X)D(Y)}$，从而有$\displaystyle{|r(X,Y)|\leqslant 1}$
3. **相关**
	1. 若$\displaystyle{r(X,Y)=0}$，则称$\displaystyle{X,Y}$不相关
	2. 若$\displaystyle{r(X,Y)>0}$，则称$\displaystyle{X,Y}$成正相关
	3. 若$\displaystyle{r(X,Y)<0}$，则称$\displaystyle{X,Y}$成负相关
	4. 需要注意的是，**相互独立必然不相关，不相关不一定相互独立**

**条件分布**：就是条件概率的推广
1. 离散
	1. 设$\displaystyle{(X,Y)}$的联合分布列为$\displaystyle{p_{ij}=P(X=x_{i},Y=y_{j})}$。给定条件$\displaystyle{Y=y_{i}}$下$\displaystyle{X}$的**条件分布列**定义为$\displaystyle{p_{i|j}=P(X=x_{i}|Y=y_{j})=\frac{P(X=x_{i},Y=y_{j})}{P(Y=y_{j})}=\frac{p_{ij}}{\sum^{\infty}_{i=1}p_{ij}}}$
	2. 从而可以定义**条件分布函数**：$\displaystyle{F(x|y_{i})=\sum_{x_{i}\leqslant x}p_{i|j}}$
	3. 给定条件$\displaystyle{X=x_{i}}$下$\displaystyle{Y}$的条件分布列也可以类似地定义
2. 连续
	1. 设$\displaystyle{(X,Y)}$的联合概率密度为$\displaystyle{p(x,y)}$。给定条件$\displaystyle{Y=y}$下$\displaystyle{X}$的**条件分布函数**定义为$\displaystyle{F(x|y)=\int^{x}_{-\infty} \frac{p(u,y)}{p_{Y}(y)}\mathrm{d}u}$
	2. 从而**条件概率密度**为$\displaystyle{p(x|y)=\frac{p(x,y)}{p_{Y}(y)}}$

性质
1. $\displaystyle{p_{Y}(y)=\int^{\infty}_{-\infty}\mathrm{d}xp_{X}(x)p(y|x)}$
2. $\displaystyle{p(x|y)=\frac{p_{X}(x)p(y|x)}{\int^{\infty}_{-\infty}p_{X}(x)p(y|x)\mathrm{d}x}}$

**条件期望**
1. $\displaystyle{E(X|Y=y)}$什么的用条件概率密度/条件分布列作为对应的概率密度/概率分布列即可
2. 性质
	1. $\displaystyle{E(X)=E(E(X|Y))}$

***大数定律***

1. 伯努利大数定律（**针对二项分布**）
	1. 设$\displaystyle{S_{n}}$为$\displaystyle{n}$重伯努利实验中事件$\displaystyle{A}$发生的次数，$\displaystyle{p}$为每次实验中试验$\displaystyle{A}$出现的概率，那么 $$\tag{4.1}\begin{align}\lim_{ n \to +\infty } P\left(\left|\frac{S_{n}}{n}-p\right|<\varepsilon\right)=1\end{align}$$
	2. 有一个等价的形式（需要记住） $$\tag{4.2}
\begin{align}
\lim_{ n \to +\infty }P\left(\left| \frac{1}{n}\sum^{n}_{i=1}X_{i}-\frac{1}{n}\sum^{n}_{i=1}E(X_{i})\right|<\varepsilon \right) =1
\end{align}
$$
2. 切比雪夫大数定律（**针对于方差存在的分布**）
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一列两两不相关的随机变量序列，且$\displaystyle{D(X_{i})\leqslant c,i=1,2,\dots}$那么有(4.2)成立
3. 马尔可夫大数定律（**不需要假定相关性**）
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一随机变量序列，且$\displaystyle{\lim_{ n \to +\infty }\frac{1}{n^{2}}D\left( \sum^{n}_{i=1}X_{i} \right)=0}$，那么有(4.2)成立
4. 辛钦大数定律（**不需要方差的存在性**）
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一独立同分布的随机变量序列，若$\displaystyle{E(X_{i})}$存在，那么有(4.2)成立

***中心极限定理***

1. 林德博格-莱维中心极限定理（独立同分布且方差存在）
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一独立同分布的随机变量序列，若$\displaystyle{E(X_{i})=\mu,D(X)=\sigma^{2}>0}$。令$\displaystyle{Y^{*}_{n}=\frac{\sum^{n}_{i=1}X_{i}-n\mu}{\sigma \sqrt{ n }}}$，那么 $$\tag{4.3}\begin{align}\lim_{ n \to +\infty }P(Y^{*}_{n}\leqslant y)=\frac{1}{\sqrt{ 2\pi }}\int^{y}_{-\infty}e^{-t^{2}/2}\mathrm{d}t\end{align}$$ ，即$\displaystyle{Y^{*}_{n}}$近似为标准正态分布
2. 棣莫弗-拉普拉斯中心极限定理（针对二项分布）
	1. 设$\displaystyle{S_{n}}$为$\displaystyle{n}$重伯努利实验中事件$\displaystyle{A}$发生的次数，$\displaystyle{p}$为每次实验中试验$\displaystyle{A}$出现的概率。记$\displaystyle{Y^{*}_{n}=\frac{S_{n}-npq}{\sqrt{ npq }}}$，那么(4.3)成立


这里会根据$\displaystyle{P(Y^{*}_{n}\leqslant y)}=\Phi(y)=\beta$出题
1. 已知$\displaystyle{n,y}$，求$\displaystyle{\beta}$（**求概率**）
	1. 一复杂系统由100个相互独立的部件组成，每各部件正常工作的概率为0.9，整个系统至少有85个部件正常工作时系统才能正常工作，问系统正常工作的概率
		1. 已知$\displaystyle{n=100,y=85}$，设正常工作的部件总数为$\displaystyle{Y_{n}\sim b(100,0.9)}$，那么$\displaystyle{E(Y_{n})=np=100\times 0.9=90,D(Y_{n})=npq=100\times 0.9\times 0.1=9}$
		2. 定义$\displaystyle{Z_{n}=\frac{Y_n-\mu}{\sigma}}=\frac{Y_{n}-90}{9}$，根据棣莫弗-拉普拉斯中心极限定理，有$\displaystyle{Z_{n}}$近似服从标准正态分布$\displaystyle{N(0,1)}$
		3. 所求概率$\displaystyle{P(Y_{n}\geqslant 85)=1-\Phi\left( \frac{85-0.5-E(Y_{n})}{\sqrt{ D(Y_{n}) }} \right)=\dots}$查表，考试会给的不用担心
2. 已知$\displaystyle{n,\beta}$，求$\displaystyle{y}$（求**分位数**）
	1. 现有同型号机器200台，一小时内每台机器约70%的时间在工作，每台机器工作相互独立，耗能1kW。问至少要提供多少电能，才有95%的可能性保证正常生产？
		1. 已知$\displaystyle{n=200,\beta=95\%}$，设同时工作的机器数量为$\displaystyle{Y_{n}\sim b(200,0.7)}$，那么$\displaystyle{E(Y_{n})=np=140, D(Y_{n})=42}$
		2. 定义$\displaystyle{Z_{n}=\frac{Y_{n}-\mu}{\sigma}=\frac{Y_{n}-140}{\sqrt{ 42 }}}$，根据棣莫弗-拉普拉斯中心极限定理，有$\displaystyle{Z_{n}}$近似服从标准正态分布$\displaystyle{N(0,1)}$
		3. 设供电量为$\displaystyle{y}$，保证正常生产有$\displaystyle{Y_{n}\leqslant y}$，那么$\displaystyle{P(Y_{n}\leqslant y)=\Phi\left( \frac{y-0.5-140}{\sqrt{ 42 }} \right)=0.95}$
3. 已知$\displaystyle{\beta,y}$，求$\displaystyle{n}$(求**样本数**)
	1. 现要求调查机器合格率$\displaystyle{p}$，在抽样样本中机器的合格频率为$\displaystyle{\hat{p}}$。现在要保证有90%的把握使得$\displaystyle{\hat{p}}$和$\displaystyle{p}$之间的差异不大于5%，问样本空间至少多大？
		1. 已知$\displaystyle{\beta=90\%, y=5\%}$，设有$\displaystyle{n}$个样本，合格样本数为$\displaystyle{Y_{n}\sim b(n,p)}$，那么$\displaystyle{E(Y_{n})=np,D(Y_{n})=npq}$
		2. 定义$\displaystyle{Z_{n}=\frac{Y_{n}-np}{\sqrt{ npq }}}$，根据棣莫弗-拉普拉斯中心极限定理，有$\displaystyle{Z_{n}}$近似服从标准正态分布$\displaystyle{N(0,1)}$
		3. 要求$\displaystyle{P\left(\left| \frac{Y_{n}}{n} -p\right|<0.05\right)=2\Phi\left(0.05\sqrt{ \frac{n}{p(1-p)} }\right)\geqslant 90\%}$，查表得到$\displaystyle{n\geqslant p(1-p)\Phi^{-1}\left( \frac{90\%}{2} \right)\geqslant \frac{1}{4}\Phi^{-1}(45\%)}$

对于其他的分布，也有类似地中心极限定理
1. 林德博格中心极限定理
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一相互独立的随机变量序列，设$\displaystyle{\lim_{ n \to \infty } \frac{1}{\tau^{2}B_{n}^{2}}\sum^{n}_{i=1}\int_{|x-\mu i|>\tau B_{n}}(x-\mu_{i})^{2}p_{i}(x)\mathrm{d}x=0}$，就有 $$\tag{4.7}\begin{align}\lim_{ n \to \infty }P\left(\frac{1}{B_{n}}\sum^{n}_{i=1}(X_{i}-\mu_{i})\leqslant x\right)=\frac{1}{\sqrt{ 2\pi }}\int^{x}_{-\infty}e^{-t^{2}/2}\mathrm{d}t\end{align}$$
2. 李雅普诺夫中心极限定理
	1. 设$\displaystyle{\left\{X_{n}\right\}}$为一相互独立的随机变量序列，设存在$\displaystyle{\delta>0}$使得$\displaystyle{\lim_{ n \to \infty } \frac{1}{B_{n}^{2+\delta}}\sum^{n}_{i=1}E(|X_{i}-\mu_{i}|^{2+\delta})=0}$，那么(4.7)成立

**总体**：研究对象的全体
**样本**：从总体中随机抽取$\displaystyle{n}$个个体，用$\displaystyle{x_{1},x_{2},\dots,x_{n}}$来代表感兴趣的指标，这就成为一个样本
**样本容量**：样本的数量$\displaystyle{n}$
**样品**：样本中的个体

**经验分布函数**：设$\displaystyle{x_{(1)},x_{(2),\dots}}$已经从小到大排列好了顺序，那么定义**经验分布函数**
$$\tag{5.1}
\begin{align}
F_{n}(x) & =\begin{cases}
0, & x<x_{(1)} \\
\frac{k}{n}, & x_{(k)}\leqslant x<x_{(k+1)} \\
1, & x\geqslant x_{(n)}
\end{cases}
\end{align}
$$

格利文科定理指出经验分布函数近似为真正的分布函数：
$$\tag{5.2}
\begin{align}
P\left(\sup_{-\infty<x<\infty}|F_{n}(x)-F(x)|\to_{0}\right)=1
\end{align}
$$

**统计量**：若样本函数$\displaystyle{T=T(x_{1},x_{2},\dots, x_{n})}$中不含任何未知参数，那么称$\displaystyle{T}$为统计量，统计量的分布称为**抽样分布**
常用统计量
1. 样本均值
	1. $\displaystyle{\bar{x}=\frac{1}{n}\sum^{n}_{i=1}x_{i}}$
	2. 抽样分布
		1. 若总体分布为$\displaystyle{N(\mu,\sigma^{2})}$，则$\displaystyle{\bar{x}\sim N\left( \mu, \frac{\sigma^{2}}{n} \right)}$
		2. 若总体分布不为$\displaystyle{N(\mu,\sigma^{2})}$，且$\displaystyle{E(x)=\mu},D(X)=\sigma^{2}$，则$\displaystyle{\bar{x}}$近似分布为$\displaystyle{N\left( \mu, \frac{\sigma^{2}}{n} \right)}$
2. 样本方差和样本标准差
	1. $\displaystyle{s^{2}=\frac{1}{n-1}\sum^{n}_{i=1}(x_{i}-\bar{x})^{2}}$
	2. 抽样分布
3. 样本矩
4. $\displaystyle{\chi^{2}}$**统计量**
	1. 设$\displaystyle{X_{1},X_{2},\dots,X_{n}}$独立同分布于标准正态分布$\displaystyle{N(0,1)}$，那么$\displaystyle{\chi^{2}=X_{1}^{2}+X_{2}^{2}+\dots+X_{n}^{2}}$服从**自由度**为$\displaystyle{n}$的$\displaystyle{\chi^{2}}$统计，记为$\displaystyle{\chi^{2}\sim \chi^{2}(n)}$
	2. $\displaystyle{p(x)=\frac{1}{2^{n/2}\Gamma(n/2)}x^{n/2-1}e^{-x/2}}$
	3. 其作用来源于下面的定理
		1. 设$\displaystyle{x_{1},\dots,x_{n}}$是来自正态总体$\displaystyle{N(\mu,\sigma^{2})}$，样本均值和样本方差分别为$\displaystyle{\bar{x}=\frac{1}{n}\sum^{n}_{i=1}x_{i},s^{2}=\frac{1}{n-1}\sum ^{n}_{i=1}(x_{i}-\bar{x})^{2}}$，那么
			1. $\displaystyle{\bar{x}}$与$\displaystyle{s^{2}}$相互独立
			2. $\displaystyle{\bar{x}\sim N\left( \frac{\mu,\sigma^{2}}{n} \right)}$
			3. $\displaystyle{\frac{(n-1)s^{2}}{\sigma^{2}}\sim \chi^{2}(n-1)}$
5. $\displaystyle{F}$**统计量**
	1. 设$\displaystyle{X_{1}\sim \chi^{2}(m),X_{2}\sim \chi^{2}(n)}$，$\displaystyle{X_{1},X_{2}}$相互独立，那么称$\displaystyle{F= \frac{X_{1}/m}{X_{2}/n}}$的分布为自由度$\displaystyle{m}$和$\displaystyle{n}$的$\displaystyle{F}$的分布，记为$\displaystyle{F\sim F(m,n)}$，其中$\displaystyle{m}$称为分子自由度，$\displaystyle{n}$为分母自由度
	2. $\displaystyle{p_{F}(y)=\frac{\Gamma\left( \frac{m+n}{2} \right)\left( \frac{m}{n} \right)^{m/2}}{\Gamma\left( \frac{m}{2} \right)\Gamma\left( \frac{n}{2} \right)}y^{m/2-1}\left( 1+\frac{my}{n} \right)^{-(m+n)/2}}$
6. $\displaystyle{t}$统计量
	1. 设$\displaystyle{X_{1}\sim N(0,1),X_{2}\sim \chi^{2}(n)}$，$\displaystyle{X_{1},X_{2}}$相互独立，那么称$\displaystyle{t=\frac{X_{1}}{\sqrt{ X_{2}/n }}}$的分布为自由度$\displaystyle{n}$的$\displaystyle{t}$分布，记为$\displaystyle{t\sim t(n)}$
	2. $\displaystyle{p_{t}(y)=\frac{\Gamma\left( \frac{n+1}{2} \right)}{\sqrt{ n\pi }\Gamma\left( \frac{n}{2} \right)}\left( 1+\frac{y^{2}}{n} \right)^{-(n+1)/2}}$
	3. 注意到$\displaystyle{\bar{x}\sim N\left( \mu, \frac{\sigma^{2}}{n} \right)}$与$\displaystyle{\frac{(n-1)s^{2}}{\sigma^{2}}\sim \chi^{2}(n-1)}$且相互独立，因此构造$\displaystyle{t=\frac{\sqrt{ n }(\bar{x}-\mu)}{s}\sim t(n-1)}$可以得到$\displaystyle{t}$分布，**因此这是假设检验中最常用的分布**

**参数估计**
**点估计**：用于估计未知参数$\displaystyle{\theta}$的统计量$\displaystyle{\hat{\theta}=\hat{\theta}(x_{1},\dots,x_{n})}$称为$\displaystyle{\theta}$的点估计
对于估计，合理的要求是**无偏**，即对于任意$\displaystyle{\theta}$，都有$\displaystyle{E(\hat{\theta})=\theta}$

样本均值$\displaystyle{\bar{x}}$是总体均值$\displaystyle{\mu}$的无偏估计；样本方差$\displaystyle{s^{2}}$是总体方差$\displaystyle{\sigma^{2}}$的无偏估计

存在参数不存在无偏估计

**矩估计**：实质是用经验分布函数代替总体分布函数
参数$\displaystyle{\theta}$能够表示成各阶矩（数学期望，方差，更高阶的矩）的函数$\displaystyle{\theta=\theta(\mu,\sigma^{2},\dots)}$，矩估计量$\displaystyle{\hat{\theta}}$就为单纯的替换总体矩为样本矩，即$\displaystyle{\hat{\theta}=\hat{\theta}(\bar{x},s^{2},\dots)}$

应注意矩估计不是唯一的，应当尽量使用较低价的矩做出估计

**最大似然估计**：设总体概率函数为$\displaystyle{p(x;\theta)}$，$\displaystyle{x_{1},x_{2},\dots,x_{n}}$为来自该总体的样本，定义似然函数
$$\tag{5.3}
\begin{align}
L(\theta)=L(\theta;x_{1},x_{2},\dots,x_{n})=p(x_{1};\theta)p(x_{2};\theta)\dots p_{n}(x_{n};\theta)
\end{align}
$$
那么$\displaystyle{\theta}$的最大似然估计$\displaystyle{\hat{\theta}}$使得似然函数取得最大值

**取对数再令导数为0**即可更加方便的解出估计量

**区间估计**
设$\displaystyle{\theta}$为总体的参数，$\displaystyle{x_{1},x_{2},\dots,x_{n}}$是来自总体的样本，对于给定$\displaystyle{\alpha}$，假设有两个统计量$\displaystyle{\hat{\theta}_{L}}$和$\displaystyle{\hat{\theta}_{R}}$使得对于任意的参数$\displaystyle{\theta}$都有
$$\tag{5.4}
\begin{align}
P_{\theta}(\hat{\theta}_{L}\leqslant \theta\leqslant \hat{\theta}_{R})\geqslant 1-\alpha
\end{align}
$$
那么称随机区间$\displaystyle{[\hat{\theta}_{L},\hat{\theta}_{R}]}$为$\displaystyle{\theta}$的**置信水平为$\displaystyle{1-\alpha}$的置信区间**。
也可以定义单侧置信区间
