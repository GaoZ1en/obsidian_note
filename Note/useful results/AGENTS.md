# AGENTS.md — Useful Results

## Scope

Compact reference notes for formulas, derivations, and quick lookup results.

## Rules

- Keep notes concise; long derivations belong in broader topic folders and should be referenced here instead of duplicated.
- Preserve quick-reference structure and notation consistency across related files.
- Update local `README.md` files when adding a new result to an indexed collection.
- Do not turn reference notes into long narrative essays unless explicitly asked.
