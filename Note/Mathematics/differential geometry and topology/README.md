# Differential Geometry And Topology

This directory collects reference material for topology, smooth manifolds, differential forms, standard spaces, and representative geometric structures.

## Notes

- `core structures.md`: point-set topology, manifolds, Lie derivatives, differential forms, Hodge star, Cartan calculus, and basic symplectic geometry.
- `standard spaces.md`: spheres, projective spaces, tori, surfaces, lens spaces, Grassmannians, and standard homology/homotopy data.

## Knowledge Structure

- point-set topology controls continuity, compactness, connectedness, and quotient behavior;
- smooth manifolds add atlases, tangent structures, differential forms, and orientations;
- standard spaces provide stable homology and homotopy data;
- Cartan calculus organizes vector fields, forms, Lie derivatives, and symplectic structures.
