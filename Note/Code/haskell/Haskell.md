# 1. Haskell基础

## 1.1 Haskell的历史

Haskell是一种纯函数式编程语言，由Miranda和ML发展而来，最早由Haskell Curry提出，1990年发布了Haskell 1.0

## 1.2 Haskell的特点

- 纯函数式编程语言
- 惰性求值
- 静态类型
- 强类型
- 类型推导
- 模块化
- 高阶函数
- 强大的类型系统
- 并发
- 递归
- 高效的数据处理
