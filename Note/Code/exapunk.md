## 第 4 页：用 EXA 进行分布式网络编程

从计算机手中夺回自主权的第一步，是知道怎样使用它们。也就是说，要学会用 EXA 编程。

### 什么是 EXA？

EXA 是 EXecution Agent（执行代理）的缩写。它是一种小程序，可以在网络中从一台计算机移动到另一台计算机，并且在移动时不中断自己正在做的事情，即使跨越巨大的现实世界距离也可以。

本十年早些时候，Axiom 和 TEC 这样的大型科技公司制定了 EXA 标准。他们当时的愿景被称为“分布式网络编程”。EXA 让世界上的一切都很容易连接到一起，因为无论底层硬件是什么，它们都能传输和处理数据。今天，它们已经成为每一个现代计算机网络的命脉。

### 代码、值和寄存器

除了在计算机网络内部看起来像有物理形体一样的存在之外，每个 EXA 都包含代码和寄存器。如果你用 EXODUS 开发环境连接到一个网络，屏幕左侧会给你的每个 EXA 显示一个窗口，你可以在里面编辑代码并查看寄存器。

**代码**是告诉 EXA 要做什么的一组指令。它使用一种专门为 EXA 设计的计算机语言编写。接下来的教程部分会深入介绍这种语言。

**寄存器**可以理解为存放值的槽位。这些值可以是数字，比如 38、5074 或 -203；也可以是关键字，比如 SECRET、TRASH WORLD NEWS 或 ABC123。代码中的指令可以读取和写入寄存器。

寄存器有不同类型。有些寄存器只是存值，因此当你读取它们时，它们会返回你最后写进去的值；X 和 T 寄存器就是这种。其他寄存器实际上是更高级功能的接口，例如读取或写入文件的 F 寄存器，或与其他 EXA 通信的 M 寄存器。你不必一开始就掌握所有寄存器。教程会教你如何使用不同类型的寄存器。

## 第 5 页：主机、链路、文件和硬件寄存器

下面是你开始用 EXA 探索网络后会看到的一些其他东西。

### 主机

主机是网络中一台计算机的表示。EXA 只能存在于主机内部。创建 EXA 时，它们会在你的主机中生成；运行它们时，它们可以上传到目标主机并在那里执行。

由于系统性能和内存限制，所有主机一次能容纳的 EXA 数量都有上限。在 EXODUS 中，这用主机内部空闲网格空间的数量表示。每个 EXA 占据一个网格空间。

### 链路

链路把各主机连接在一起，EXA 通过链路在主机之间移动。链路两端都有数字 ID，你可以在代码中引用它们。大多数链路可以双向通过，但有些只能单向通过，还有一些根本不能使用。

### 文件

文件存储值的序列，包括数字和关键字。文件有点像 EXA，因为它们存在于主机里并占据空间；但它们没有自己的代码或行为。它们唯一的目的就是存储值。

要处理文件，你需要使用 EXA。EXA 可以创建和删除文件，写入和读取文件，也可以通过抓取和放下文件来移动它们。和链路一样，每个文件都有一个数字 ID，代码可以借此引用它。

### 硬件寄存器

某些主机包含特殊的硬件寄存器。这些寄存器和可能连接到主机的外部硬件有关。具体完全取决于系统，因此这些寄存器有时只读或只写，有时既可读也可写。寄存器可以包含数字或关键字。它们的名称由一个井号加四个字符组成，例如 # POWR 或 # ENAB。你可以在代码中直接使用这些名称。

信息确实不少，所以如果你没有一次全懂也没关系。接下来的部分包含一些教程，让你亲手使用这个系统，并真正开始学习它。

## 第 6 页：Ghast 带你从头过一遍，教程 1 与教程 2

我真心相信任何人都能学会 EXA 编程。所以我搭了一个带教程的网络，你可以试一试。即使你觉得自己不是程序员，也可以试一下。你也许会让自己吃惊。

### 教程 1：基础

第一个教程的目标是把 ID 为 200 的特定文件，从名为“inbox”的主机移动到名为“outbox”的主机。你要通过 ID 为 800 的链路移动它。

启动 EXODUS 并连接到教程网络。系统会自动为你创建一个新的空白 solution。所谓 solution，只是一组 EXA；当你按下运行按钮时，它们会开始执行。

屏幕左侧会有一个空的 EXA 和空白代码窗口。把下面五行代码输入 EXA：

```text
LINK 800    通过链路 800 进入网络
GRAB 200    抓取文件 200
LINK 800    通过链路 800 从“inbox”到“outbox”
DROP        放下持有的文件
HALT        终止该 EXA
```

按 step 按钮可以一次执行一条指令。觉得无聊时，可以按 run 按钮让它自己运行。

确认程序确实在做你想做的事之后，可以按快进按钮，让程序一直运行到结束。恭喜，你刚刚编写了第一个 EXA 程序。

### 教程 2：读取和写入文件

下一个任务和第一个很像，只是你需要读取和写入文件，而不只是移动它。请阅读 EXODUS 中的要求说明。现在就去做。

要读取或写入 EXA 持有的文件，我们必须使用 F 寄存器。我们还会使用 X 寄存器，在运算过程中存储中间值。把下面的代码输入默认的空 EXA：

```text
LINK 800     通过链路 800 进入网络
GRAB 200     抓取文件 200
COPY F X     从 F 读取，并把值写入 X
ADDI X F X   计算 X + F，并把结果写入 X
MULI X F X   计算 X × F，并把结果写入 X
SUBI X F X   计算 X - F，并把结果写入 X
COPY X F     从 X 读取，并把值写入 F
LINK 800     通过链路 800 从“inbox”到“outbox”
DROP         放下持有的文件
HALT         终止该 EXA
```

逐步执行程序并执行 GRAB 指令时，注意文件 200 的窗口会如何出现在当前持有它的 EXA 窗口下方。还要注意文件窗口中的“文件光标”，它会高亮文件中的第一个值。当 EXA 从 F 寄存器读取时，它会读取文件光标指向的值。同样，写入 F 寄存器会替换文件光标指向的值。如果文件光标在文件末尾，那么写入的新值会追加进去，而不是替换已有值。

还有一点：读取或写入 F 寄存器会自动把文件光标移动到文件中的下一个值。有时这很方便，有时并不方便。

## 第 7 页：教程 3 与教程 4

### 教程 3：EXA 之间的通信

下一个教程涉及一个只能通过单向链路访问的文件。去抓取文件的 EXA 会被困住，所以你需要创建两个 EXA，并让它们彼此通信。

这一次代码就让你自己想，不过下面有一些提示：

- 可以用 MAKE 指令创建新文件。它创建的文件默认为空，并且会自动被创建它的 EXA 持有。
- EXA 可以用 WIPE 指令删除自己持有的文件。
- 两个 EXA 可以通过 M 寄存器通信。如果一个 EXA 向 M 寄存器写入一个值，而另一个 EXA 从 M 寄存器读取，那么这个值就会从写入者传输给读取者。
- 如果一个 EXA 正在读取 M 寄存器而没有其他 EXA 正在写入，或者反过来，一个 EXA 正在写入而没有其他 EXA 正在读取，它会等待，直到另一个 EXA 接上通信的另一端。你不需要把时机卡得完美。
- EXODUS 用户界面里有一个切换开关，可以把 M 寄存器设为全局或本地操作。在全局模式下，只要两个 EXA 所在位置之间有链路路径相连，它们就可以在网络中任意位置通信。在本地模式下，两个 EXA 只有在同一主机中才能通信。最后，一个处于全局模式的 EXA 不能和一个处于本地模式的 EXA 通信，即使它们在同一主机中也不行。

### 教程 4：循环与条件

最终任务是创建一个包含一串数字的文件。为此，你会想要使用一种叫做循环的东西：反复运行几行代码，直到满足停止条件。提示如下：

- 可以用 TEST 指令比较寄存器和/或值，例如测试 X 是否等于 38：`TEST X = 38`。如果测试为真，T 寄存器会被设为 1；如果测试为假，T 寄存器会被设为 0。
- TEST 指令本身没那么有用，但如果把它和条件跳转指令 TJMP、FJMP 结合起来，就可以根据测试结果跳转到程序的不同部分。TJMP（真则跳转）在 T 寄存器为 1 时生效。FJMP（假则跳转）在 T 寄存器为 0 时生效。看出联系了吗？你还需要在程序其他地方用 MARK 指令指定跳转目标。
- 下面是一个循环例子。假设你想把值 9999 写入一个文件 10 次，可以这样做。它用 X 寄存器记录循环已经执行的次数：

```text
COPY 0 X      把 X 寄存器重置为 0
MARK LOOP     定义一个名为 LOOP 的标签
COPY 9999 F   把 9999 写入持有的文件
ADDI X 1 X    把 X 加 1
TEST X = 10   测试 X 是否等于 10，并把结果存入 T
FJMP LOOP     如果 X 还不等于 10，就跳转到 LOOP
```

- 当 TJMP 和 FJMP 指令查看 T 中的值时，它们并不关心这个值是由 TEST 指令放进去的，还是你自己放进去的。事实上，你可以在 T 寄存器中存放任何数据，只要你能接受下一次执行 TEST 指令时它会被清掉。

好了，你已经完成教程了。恭喜。可以把自己当成真正的 EXA 程序员了。永远还有更多东西可学，但基础已经都在这里了。

## 第 8 页：运行时错误，以及如何利用它们

有时 EXA 会试图做它们不被允许做的事。发生这种情况时，该 EXA 会被主机自动终止。功能上，这和它运行了一条 HALT 指令一样。虽然大多数错误都很无聊，也没什么用，但有一些错误可以为你所用。

先从一些无聊的错误开始：

### 除以零

计算机上不能除以零。某种数学原因。别太担心理解为什么，别这么做就行。

### 用关键字做数学运算

你不能对关键字执行加法、减法、乘法等运算。数学运算仅限于数值。

### 无效的 F 寄存器访问

如果 EXA 没有持有文件，却读取或写入 F 寄存器，它会报错并死亡。别忘了先把文件拿起来。

### 无效的硬件寄存器访问

和上一条类似。试图读取或写入某个硬件寄存器之前，确保你和想访问的硬件寄存器在同一主机中。

你写代码和修代码时大概会遇到很多这样的错误。但现在来谈谈更有趣的错误类型。

有时你并不知道正在操作的主机的所有细节。链路会变化，文件会消失。有些关于运行环境的信息，只有通过尝试执行代码并可能失败才能知道。你也许觉得这很乱，但你又不是在某个大型软件公司工作，不会因为这种混乱而被人皱眉指责；如果你确实在那样的地方工作，那我很遗憾，也许该考虑换一种人生了。这里唯一重要的事情就是把任务完成。

下面这些错误就更适合利用：

### 无效文件访问

假设你在寻找某个特定文件。尝试访问它的 EXA 会终止，但现在你知道这个文件不在那里了。

### 无效链路穿越

假设你在寻找某个特定链路。尝试穿越它的 EXA 会终止，但现在你知道这个链路不在那里了……看到模式了吗？

说真的，别害怕让你的 EXA 出错、崩溃、死亡，随你怎么称呼。它们也许看起来很可爱，但记住，它们生命的意义就是反复生成、计算，然后死亡。你可以在程序中利用这一点。

## 第 9 页：Axiom EXA 语言参考指南（一）

EXA 虚拟机（EXA-VM）允许许多执行代理（EXA）在一个由主机计算机组成的共享网络中执行。在网络内部，EXA 可以被动态创建、销毁，并从一台主机转移到另一台主机。EXA-VM 让所有 EXA 都可以独立且同时运行，即使多个 EXA 位于同一主机中也是如此。

一个 EXA 程序由一系列指令组成。每条指令需要零个或多个操作数。每条指令所需的操作数用简写表示：

```text
R      一个寄存器
R/N    一个寄存器，或 -9999 到 9999 之间的数字
L      由 MARK 伪指令定义的标签
```

### 寄存器

**X 寄存器**是通用存储寄存器，可以存储数字或关键字。

**T 寄存器**也是通用存储寄存器，可以存储数字或关键字。它同时是 TEST 指令的目标寄存器，也是条件跳转 TJMP 和 FJMP 的判定依据。

**F 寄存器**允许 EXA 读取和写入所持有文件的内容。当 EXA 抓取一个文件时，它的“文件光标”会设到文件中的第一个值。读取 F 寄存器会读取这个值；写入 F 寄存器会覆盖这个值。每次读取或写入 F 寄存器后，文件光标会自动前进。写到文件末尾时，会追加一个新值，而不是覆盖已有值。

**M 寄存器**控制 EXA 的消息传递功能。当 EXA 写入 M 寄存器时，该值会存储在这个 EXA 的输出消息槽中，直到另一个 EXA 从 M 寄存器读取并接收先前写入的值。数字和关键字都可以用这种方式传递。

如果 EXA 写入 M 寄存器，它会暂停执行，直到该值被另一个 EXA 读取。如果 EXA 从 M 寄存器读取，它会暂停执行，直到有值可读。如果两个或更多 EXA 同时试图从另一个 EXA 读取，或反过来，只有一个会成功，但具体哪个成功不可预测。

默认情况下，EXA 可以和同一网络中的任何其他 EXA 通信。你可以在 EXODUS 界面中切换 global/local 设置，或执行 MODE 指令，把通信限制到同一主机内的 EXA。全局模式下的 EXA 不能和本地模式下的 EXA 通信，即使它们在同一主机中也不行。

### 硬件寄存器

某些运行 EXA-VM 的主机可能通过硬件寄存器提供对连接硬件的访问。有效的硬件寄存器名称由井号 `#` 加四个字符组成，例如 `#POWR` 或 `#ENAB`。根据主机配置，硬件寄存器可以可读可写、只读，或只写。

### 指令：操作值

```text
COPY R/N R
```
把第一个操作数的值复制到第二个操作数中。

```text
ADDI R/N R/N R
```
把第一个操作数的值加到第二个操作数的值上，并把结果存储到第三个操作数中。SUBI（减法）、MULI（乘法）、DIVI（除法）和 MODI（取模）指令使用相同语法。

```text
SWIZ R/N R/N R
```
使用第二个操作数作为 swizzle 掩码，对第一个操作数的值进行 swizzle，并把结果存储到第三个操作数中。SWIZ 指令可用于重排和/或提取数字中的数位。例如：

```text
输入  掩码   结果
6789  4321   6789
6789  1234   9876
6789  3333   7777
6789  1211   9899
6789 -4321  -6789
-6789 -4321   6789
6789  2000   8000
6789  0001   0009
```

### 指令：分支

```text
MARK L
```
用指定标签标记这一行。MARK 是伪指令，不会被执行。

```text
JUMP L
```
跳转到指定标签。

```text
TJMP L
```
如果 T 寄存器等于 1，或等于任何非 0 值，则跳转到指定标签。这对应于 TEST 结果为真。

```text
FJMP L
```
如果 T 寄存器等于 0，则跳转到指定标签。这对应于 TEST 结果为假。

## 第 10 页：Axiom EXA 语言参考指南（二）

### 指令：测试值

```text
TEST R/N = R/N
```
比较第一个操作数和第二个操作数的值。如果相等，把 T 寄存器设为 1；否则设为 0。`<`（小于）和 `>`（大于）测试使用相同语法。

```text
TEST R/N = R/N
TEST R/N < R/N
TEST R/N > R/N
```

数字/数字：测试相等；测试数值顺序。

## 第 11 页：调试“噬菌体”（一）

一种俗称“噬菌体”的神秘疾病会缓慢地把人体变成计算机部件。听起来像科幻小说或阴谋论者的领域，但在这个案例中，它遗憾地完全真实。医学界把噬菌体称为“进行性神经可塑性功能障碍”（Progressive Neuroplastic Dysfunction，这个名字已经过时，而且完全不准确），或者较少使用的“Wurzner 综合征”。

乍看起来，变成计算机也许听上去很酷，像变成半机械人。不幸的是，噬菌体不会把你的身体变成任何类似可工作计算机的东西。如果不加控制，噬菌体会把身体变成一种无生命的、无目的电路混合物。

我们知道，经常使用计算机的人更容易患病；所有已知病例都发生在每天使用计算机八小时或更久的人身上。它会在六到十八个月内从四肢向身体核心扩散，通常从手开始，偶尔从脚开始，逐渐用一种塑料状物质的连接结构替换身体细胞，这种物质包含半导电的子结构。

目前治疗噬菌体的最佳选择，是受影响组织一出现就尽快切除，这显然很不理想。还有几种治疗方案正在开发中。有一种超适应症口服药似乎能有效减缓扩散，但对大多数潜在患者来说价格高得无法承受。

除此之外，我们对噬菌体的理解仍然很差，因此各种猜测很快填补了空白。有人声称噬菌体是某个秘密政府实验室研究人机接口时逃逸的实验产物，这无法验证；那些关于某种神秘“计算机升天”的荒唐想法同样无法验证，据说碳基生命和硅基生命会结合成一种新的高级意识形态。

## 第 15 页：访问遗留存储系统中的数据

计算机技术发展很快，意味着很多东西被抛在后面；而向基于 EXA 的计算快速转移，也让旧存储介质上留下了大量有意思的数据。访问 EXA 时代之前的存储可能很别扭，但也可能很有收获。你永远不知道自己会找到什么。下面是几种较旧的存储格式，以及如何读取它们。

### 磁带存储系统

磁带存储系统过去常用于长期存储或备份。一个 EXA 可访问的磁带存储系统通常由每个磁带单元对应一个主机构成，每个单元的磁带作为一个可读写文件挂载。

每盘磁带包含零个或多个备份条目。这些条目的数据从磁带开头开始，按顺序串接起来，因此不可能直接看出哪些数据属于哪个备份条目。糟糕！要取回这些数据得花点功夫。

条目的元数据存储在文件末尾，以三个值为一组。第一个值是条目名称，第二个值是该条目数据在数据流中的起始偏移量（0 表示开头），第三个值是条目长度。

例如，要获取元数据为 “SECRET, 3, 4” 的条目数据，你要到文件开头，跳过前三个值，然后按顺序读出接下来的四个值。

### 硬盘阵列

硬盘阵列在今天仍被用于某些应用。因为它们把一个文件的数据分散存储在多个硬盘上，所以读写更快，但访问起来也比单个硬盘更复杂。

在阵列内部，每块硬盘通常映射到自己的主机，并包含最多 10 个文件，从文件 ID 200 到 209。每个文件包含 100 个值，分成 10 个块，每块 10 个值。

第一块硬盘中的第一个文件 200 应该包含该硬盘阵列中所有备份条目的表。每个条目由条目名称以及存储该条目数据的块地址组成。

块地址是 100 到 999 之间的数字，指向硬盘阵列某处的一个块。第一位数字表示包含该块的硬盘（1–9），第二位数字表示包含该块的文件（0–9，对应文件 200–209），最后一位数字表示该块在目标文件中的位置（0–9，对应偏移量 0 到 90）。

例如，要取回块 527，你需要访问 5 号硬盘，抓取文件 202，seek 到偏移量 70，然后读取接下来的 10 个值，也就是一个块的大小。嘿，其实也没那么复杂！

既然我已经设定好了你的预期，就进入正题。首先要知道的是，虽然 Equity First 是大家都爱恨交加的超级大银行，但我们没理由被吓住。我得以窥探他们网络内部，发现他们的内部服务器结构和其他银行并没有太大不同。事实上，它们相当简单。

账户以单独文件存储，每个账户一个文件。每个账户文件开头都有四个值。依次是：账户号码、账户名称、表示账户类型的数字（目前我发现 2 表示支票账户，7 表示贷款；其他数字一定对应其他账户类型），然后总是一个 1，不知道它是干什么的，也许是供将来使用的占位符。

示例含义：从账户 C29374（LINDA WALLACE）向 C94872（FASHION ALLEY）转账 33.50 美元。

在网络后部，你会看到许多通过拨号连接接入的 ATM。Equity First 的 ATM 只发放 20 美元面额的钞票，因此 `#CASH` 寄存器告诉你剩余的是多少张钞票，而不是剩余多少钱。如果你向 `#DISP` 寄存器写入 20，它会尝试发放一张钞票；但如果 ATM 没有钞票了，它会发送失败消息并警告银行。所以小心点！

### 做法

什么？上火！这是烤箱的一个功能，接下来你会学会怎么用它。通常烤箱会试图让内部均匀受热，但开启上火模式会打开顶部的加热元件，向正下方的东西辐射荒谬多的热量。你用它让食物顶部或边缘变脆，作为最后一步。它让鸡皮变脆、奶酪融化冒泡、三文鱼排边缘轻微焦香。烹饪真棒！

这个方法有效，是因为上火会烘烤甜甜圈外层，使它们更好吃，同时让顶部的糖霜或釉面焦糖化，使它变脆且格外美味。你也可以用小烤箱这样做，不过它大概不能像真正的上火那样让糖霜焦糖化。不要使用下压式吐司机；糖霜会滴下去、烧焦，并让你的房子充满烟，或者火。

现在你拥有了绝妙的温热甜甜圈，而且完全免费，或很便宜！还有很多很棒的菜可以用上火完成，不过那些以后再说。现在，享受升级后的甜甜圈吧。

步骤：

1. 拿出你的垃圾箱甜甜圈，或折扣甜甜圈。
1. 用微波炉短暂加热，直到内部变软；单个甜甜圈大约 10 秒。
1. 放在金属托盘或锡纸上。
1. 打开烤箱上火模式。
1. 放入烤箱并调整架子，让甜甜圈距离上火约 2 英寸。
1. 保持烤箱门打开。
1. 盯着看，因为上火又热又快。
1. 甜甜圈开始上色但还没烧焦时取出；约 1 到 2 分钟。

## 第 19 页：《Passing Resemblance》（第一部分，一）

**编者按**：这次来点不一样的东西。这是一篇关于一个被技术改变的世界的小说。它还不是我们的世界，但也许是一个可能到来的未来……

享受这个故事，并在下一期寻找它的结局。

作者：Loveless

当我第一次知道自己是试管婴儿时，我想象的是一排排宽大的玻璃培养罐，里面有胎儿在生长，成簇排列在昏暗灯光下的实验室里。我的母亲 Sharon 向我解释细胞和线粒体之类的东西；而我的年轻保姆 Maria 正抚摸着我湿漉漉的头发，把它哄进一个发圈里。Sharon 俯身越过早餐吧台，在一张随手拿来的索引卡上画了一个没有固定形状的 blob。

“这是一个细胞，所有生命的基本单位。”

那年我六岁。那也是 Maria 在我们家工作的最后一年。

什么使一个人成为母亲？是怀着一个孩子吗？仅仅是分娩这一行为定义了母职吗？还是养育和照料这一行为？

Sharon 从来不需要男人，但这不是因为她是激进女权主义者，或极端独立。她只是从没想过这件事。她不需要任何其他人来创造一个孩子。

Sharon 曾是 Powell Institute for Science 一名很有前途的研究员，在罗马尼亚、乌克兰和美国各地工作。但在十五年的徒劳努力与破裂合作之后，她对 C 级高管的鄙夷把她推向了一种更犬儒的东西：管理岗位。于是，她很快适应了实验室里的这套角色，一阶一阶爬上公司梯子，并在前进时砍掉身后的梯级。

“她为什么这么无情？”追悼会前几天，我问 Ben。他停顿了一下，把我在同一个早餐吧台上做出来的那杯勉强能称为咖啡的东西放下。他耸了耸肩。

我想念 Maria：她会给我编辫子，唱歌，还会用她的尤克里里伴奏。她的头发卷曲，有酒窝，而且很容易晒黑。Sharon 和我则有同样的纸白皮肤，只要想到太阳就会起水泡。

Maria 曾把我抱在腿上摇晃，我们一起看老动画片。她会喂我花生酱饼干，用手梳理我的头发。她的头发很厚很长，垂到腰下，并且总是编成一条紧紧的辫子。她是美人鱼吗？我问过她至少一次。她只是笑了笑。

“Maria 去哪儿了？”

“Maria 要开始自己的家庭了。”

一阵苦涩闪过我全身。然后困惑的雾气涌上眼睛。

“开始自己的家庭？”

“Maria 遇到了一个不错的年轻男人，要结婚了。”

“你的年轻男人在哪里？”

Sharon 对我咧嘴笑，把手放在我的肩上。

“是时候开始你的教育了。”

Maria 离开后不久，Sharon 带回家一台亮紫色的一体式计算机。她说，那是 Powell Institute 人工智能部门送来的礼物。Sharon 满面笑容，蹲到我身边，这是我在那个圣诞清晨最接近圣诞妈妈的一刻。我打开它。计算机发出叮声和呼啸的启动音，一个波浪状的运动标志在反光屏幕上旋转。

“你好，”设备里的一个声音说，“我叫 JODI。你叫什么？”

我盯着它，看见我们两人的倒影映在屏幕中。

“谢谢，”我说。

“你好 Minx，”JODI 说。

“还有一些问题，但 AI 组总说补丁很有前景。我想你会真的喜欢有一个虚拟……朋友。”

接下来的三年里，我从未纠正 JODI，而她继续叫我 Minx。

Sharon 总是想做对我、也对她自己最好的事。所以，在又一个名叫 Rosaline 的女人怀着我。

我第一次听到她的名字，是偷听 Sharon 和 Ben 说话时。我迷上了它。我在空气中描摹她名字的草书字母 R。我想象她的脸，虽然我知道它一点也不像我，也不像 Sharon。

## 第 20 页：《Passing Resemblance》（第一部分，二）

Rosaline。Rosaline。我想象她是一个有着赤褐色长发和绿色眼睛的公主。我想象她是一个脸颊红润、有纹身的离家出走者。她是诗人。她是宇航员。她是外科医生。她是舞者。她是创造者。她是母亲。

“JODI，Rosaline 这个名字是什么意思？”

“Rosaline 是威廉·莎士比亚《罗密欧与朱丽叶》中的一个次要角色。它是 Rosalind 这个名字的变体，意思是柔软的马。”

一如既往，JODI 给我兴奋的想象泼了冷水。

JODI 最终并没有成为 Institute 所期待的那种顶级家庭教育助手。九岁时，Sharon 把 Priya 和 Ben 介绍给我。他们将成为我的私人导师，教授一切与科学、技术、工程和数学有关的科目。没有其他科目。

Priya 和 Ben 每周三次成对出现，带着他们的便携计算机，偶尔甚至带一本教材。Priya 会坚持说，这是“为了基础”。三角学和微积分来自 Priya，像方程和变量的喷泉一样涌出。Ben 负责生物和化学。只有在我证明了自己的数学能力之后，Priya 才允许我后来学习物理。他们两人在一起时互相摩擦、互相烦扰，像两块磁铁。但他们教会我对数和算法、力学和动力学、有丝分裂和共生。

到十四岁时，我已经超过了私立中学毕业的要求。为了庆祝这项成就，Priya、Ben 和我挤进 Priya 的小型电动车，开去了 Dairy Queen。

我们回到公寓时，Sharon 打开门，对我微笑。

“现在我们可以开始你真正的教育了。”

“什么意思？”

“你要开始在 Powell Institute 工作了。跟我一起。”

“跟我们一起，”Priya 补充。

Sharon 看了 Priya 一眼，又看了 Ben 一眼。

“你下巴上有冰淇淋。”

然后她消失在公寓昏暗的入口走廊里。
