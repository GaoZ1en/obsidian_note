## overview

### no bulk dofs

we know

$$
\tag{2.1}
\begin{align}
R_{\mu \nu \rho \sigma}=W_{\mu \nu \rho \sigma}+ \frac{2}{n-2}(g_{\rho[\mu}R_{\nu]\sigma}+R_{\rho[\mu}g_{\nu]\sigma})- \frac{2}{(n-1)(n-2)}Rg_{\rho[\mu}g_{\nu]\sigma}
\end{align}
$$

in $\displaystyle{3d}$, the independent components in the Riemann tensor is $\displaystyle{6}$, which matches with the number of independent components of Ricci tensor, so $\displaystyle{W_{\mu \nu \rho \sigma}=0}$, which implies that there is no propagating degree of freedom.

### Einstein-Hilbert action and homogeneous spacetimes

the action is

$$
\tag{2.2}
\begin{align}
S & =-\frac{1}{16\pi G}\int _{M}\varepsilon(R+2\Lambda)
\end{align}
$$

and the solution of the eom gives

$$
\tag{2.3}
\begin{align}
R_{\mu \nu \rho \sigma}\approx 2\Lambda g_{\mu [\rho}g_{\nu]\sigma}
\end{align}
$$

- if $\displaystyle{\Lambda>0}$, locally dS
- if $\displaystyle{\Lambda=0}$, locally Minkowski
- if $\displaystyle{\Lambda<0}$, locally AdS

here we mainly study the case $\displaystyle{\Lambda\leqslant 0}$, since we don't know how to handle with dS space.
