# Usefulness for CPS language

This paper is not a technical CPS construction. Its value is as a warning about overusing the slogan "physical observables are phase-space functions commuting with the constraints." In boundary and covariant phase-space work, it is tempting to identify the full invariant content with functions on a reduced phase space. The source argues, using temporally diffeomorphism-invariant mechanical models, that this can miss invariant relational and temporal structure.

The note is medium-priority because it helps police language around relational observables, constraints, and quotienting, but it does not provide a new gravitational charge or boundary symplectic form.

# Frozen-observable setup

In a constrained Hamiltonian model, gauge transformations are generated by a constraint combination $G$. For canonical coordinates $q^a,p_a$, the infinitesimal flow is

$$\begin{align}
\frac{dq^a(\xi)}{d\xi}=\{q^a,G\},\qquad
\frac{dp_a(\xi)}{d\xi}=\{p_a,G\}.
\end{align}$$

For a smooth phase-space function $f$, the corresponding transformation is

$$\begin{align}
\frac{df(\xi)}{d\xi}=\{f,G\}.
\end{align}$$

The "frozen observable" view then identifies physical quantities with functions $O$ satisfying

$$\begin{align}
\{O,\mathcal H\}=0,
\end{align}$$

where $\mathcal H$ is the generator of temporal diffeomorphisms. The paper's target is the stronger interpretation that all physical content of a diffeomorphism-invariant model can be encoded by such smooth invariant functions, often understood as correlations.

# Why correlations can fail as smooth functions

The source analyzes temporally diffeomorphism-invariant models where one subsystem is used as a clock for another subsystem. The usual relational construction asks for the value of some variable $Y$ when a clock variable $T$ takes a chosen value. This is straightforward only when the clock gives a good global parameter along each orbit.

The obstruction is that many systems are periodic, non-monotonic, or have turning points. Then the same clock reading can occur multiple times along a single dynamical orbit, and the proposed correlation

$$\begin{align}
Y\ \text{when}\ T=T_0
\end{align}$$

is multivalued or branch-dependent. The object may still be meaningful after adding branch data, restricting the domain, or weakening smoothness, but it is not a globally defined smooth phase-space function with a standard Poisson bracket.

This matters for local usage: when a boundary reference frame or relational clock is introduced, the phase-space function may only exist on a domain where the reference field is monotone and nondegenerate.

# Generalized invariance

The paper's second move is to separate invariance from smooth Poisson commutation. A quantity can be invariant along gauge orbits without being a smooth function on the whole phase space. Once the object is defined only on a subspace, or is discontinuous through branch changes, the expression

$$\begin{align}
\{O,\mathcal H\}=0
\end{align}$$

may not even be meaningful. The invariant content is then better described as orbit-invariant data, not necessarily as a differentiable function on the ambient phase space.

For CPS comparison, this is analogous to the difference between:

1. a smooth Hamiltonian charge function on a phase space;
1. a relational rule or boundary-data assignment that is invariant under gauge transformations but not globally smooth;
1. a quotient-space structure that is only stratified or locally defined.

# Temporal and spatiotemporal relations

The most reusable formal object in the paper is the time-ordering construction. Let $\tau_\lambda(X,x)$ denote the parameter value at which a phase-space trajectory with initial data $x$ reaches a point or event $X$, for a choice of temporal smearing or lapse-like data $\lambda$. For two events $X_1,X_2$, the source defines a time-ordering function

$$\begin{align}
{\rm TO}(X_1,X_2,x)
=\operatorname{sign}\!\left(\tau_\lambda(X_1,x)-\tau_\lambda(X_2,x)\right).
\end{align}$$

Changing $\lambda$ or shifting $x$ along the same dynamical trajectory corresponds to a temporal diffeomorphism connected to the identity, and does not change temporal orientation. Thus ${\rm TO}$ is invariant, even though it is not a conventional smooth phase-space observable.

The same idea gives an in-betweenness relation

$$\begin{align}
{\rm IB}(X_1,X_2,X_3,x)
={\rm TO}(X_1,X_2,x)\,{\rm TO}(X_2,X_3,x),
\end{align}$$

which records whether $X_2$ lies temporally between $X_1$ and $X_3$. These are invariant spatiotemporal structures rather than equal-time correlations.

# Reading consequence for local projects

The paper should be used as a conceptual guardrail, not as a computational engine. In charge/CPS notes, one can still use Hamiltonian generators, reduced phase spaces, and Poisson brackets. But one should avoid the stronger claim that all invariant content is exhausted by smooth Poisson-commuting functions.

The safer statement is:

1. smooth charges and observables are one class of invariant quantities;
1. relational observables can fail to be smooth or single-valued without good reference fields;
1. temporal order, in-betweenness, and other spatiotemporal relations can be invariant data even when they are not ordinary phase-space functions.
