# Symmetry scan — 对称性探索

帮助研究者判断：这个模型中，什么结构值得怀疑背后存在对称性，为什么，以及怎样把这个想法变成可以研究的具体变换。

核心原则：从理论中已有的结构和未解释的规律出发，猜测哪些变化可能相互补偿；让猜测决定计算。保持探索的主动性，允许更换变量、借用相近理论的机制或提出表外的方向。

## 思考原则

- **理论对哪些区别不敏感？** 方程只依赖某些组合时，什么变化保持这些组合？几个场以相同方式进入时，能否混合？几何、场和耦合中的哪些变化可能相互补偿？
- **当前表示藏起了什么？** 场强、势、正则变量、对偶变量或另一种几何描述，能否暴露一个自然的候选变换？换表示应有具体动机，并追踪候选回到原变量后的意义。
- **什么规律还没有解释？** 可分离性、额外守恒量、谱或解族的对应、特殊参数处的简化，是否提示某种作用在解上的变换？把这些现象当作线索，同时考虑其他解释。
- **什么恰好破坏了已知对称性？** 从可理解的极限或相近模型出发，找出质量、相互作用、曲率或边界带来的具体破坏项；考虑修正变换、特殊参数或真正的障碍。

## 可考虑的方向

下面是启发性的方向，不是完整分类，也没有执行顺序。它们可以重叠；只有当前模型提供理由时才展开。指出支撑猜测的具体项、几何结构或现象，比列出方向名称更重要。

| 方向 | 什么线索值得沿这个方向想？ |
| --- | --- |
| 时空与几何对称性 | 背景有哪些等距或共形结构？坐标变化能否与场的变换、权重相配合？质量、耦合和边界引入的尺度是否构成障碍？ |
| 内部与场空间对称性 | 哪些分量具有相同的动力学与耦合结构？场的平移、相位、旋转或非线性混合，能否保持相关组合？场空间几何是否提供候选？ |
| 离散对称性 | 反射、时间反演、复共轭、符号翻转或场的交换，是否保持同一个问题？注意组合变换的可能性。 |
| 隐藏与动力学对称性 | 已知对称性未解释的守恒量、可分离性或简并，是否提示额外的相空间变换、Killing 张量或作用于解的微分算子？ |
| 导数依赖的广义对称性与可积结构 | 当只依赖坐标和场的变换不足时，具体结构是否提示导数项？已有额外流、Lax 表示或递推关系时，能否据此猜测新的相容变换？ |
| 对偶、势变量与非局部变换 | 方程与恒等式之间的对应、不同势描述或正则变量的交换，是否使一个候选变得简单？它作用在同一理论内，还是联系不同理论？ |
| 规范与约束结构 | 任意函数自由度、微分恒等式或约束结构提示什么冗余？规范固定后是否有残余变换，或者一个几何变换需要补偿性的规范变换？ |
| 边界与渐近对称性 | 给定边界条件允许哪些变换？哪些边界行为值得进一步检查是否具有非平凡荷？保留边界处的规范参数对判断是否有意义？ |
| 特殊参数、极限与变形 | 无质量、自由、临界或其他有依据的极限，是否显露额外结构？打开被忽略的项后，候选能否延拓，或只在明确的近似阶数成立？ |

若模型本身提供分级结构、扩展观测量等线索，也可考虑超对称或 higher-form symmetry 等方向。这里导数依赖的 generalized symmetry 与 higher-form symmetry 是不同概念；无需为了补齐类别而引入它们。

## 怎样把方向变成研究

结合用户材料，讲清最有依据的猜测，指出它依赖的具体结构，并推进能区分这个猜测与其他解释的计算或论证。候选形式可以由几何、量纲、已知极限、变量变换或相近理论启发；采用 ansatz 时说明动机，让计算中的破坏项帮助修正它。

工具和文献用于回答已经出现的问题。需要验证时遵循仓库的数学检查约定，选择合适的计算工具；需要了解已有结果时针对模型和机制检索。不要默认建立程序、扫描多个阶数、跑基准或生成统一报告。用户只问思路时，给出方向及理由；用户要求推进时，主动做相关研究。

明确所讨论的对象：方程、作用量、允许的解空间和边界问题，其对称性要求可能不同。保持固定的背景、参数及边界数据不能暗中随变换改变；如果确实允许它们变化，应说明研究的是哪一族理论。线性化方程或约化系统中的候选，也需要另问能否延拓到原理论。

换表示、发现简并或得到一个守恒量，尚不单独证明存在所猜测的对称性；已知生成元的复合与新的独立结构也要分清。结论用自然语言区分猜测、已验证范围和未解决之处。一次尝试失败只排除该尝试，能否扩大结论取决于额外证据。
