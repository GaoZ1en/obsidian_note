## Safe replay rule

Each self-contained input computes its export path from `DirectoryName[$InputFileName]` and a fixed output basename. **Do not evaluate the preserved input in place**, because that would overwrite its frozen generated output. Copy the desired input to a newly created unique replay directory, then evaluate the copy. The export will then go to that replay directory. Alternatively, change the output destination in a new copy of the input. Never alter the frozen input or its recorded output for replay.

This is a file-placement requirement, not a mathematical change. The inputs use no external packages and execute no shell commands. Their actual executed results are the preserved outputs linked above; a later replay must be labeled as a new run.
