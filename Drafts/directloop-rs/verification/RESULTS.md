# 验证与实测结果

本页保留首版 `L=22` 基准。当前默认算法与配置已更新，见 `OPTIMIZATION.md`。

日期：2026-10-16。平台：Apple M5，10 核 CPU、16 GB 内存，macOS 26.5.1；Rust 1.99.1，Mathematica 14.3。以下是本机实测，未在 i9-14900HX / Linux 上编译或计时。

## 一致性

**Verified:**

- `cargo test --release --locked`：9 项测试通过。覆盖精确消元、整数溢出后的大整数运算、规范代表、短路径穷举、线程异常传播、断点续算和 Mathematica 数据对照。
- 原 notebook 逐项导出到 `L=16`：全部 7 个非空检查长度的完整基、seed、SDE 系数和规范化 TrE 记录一致；另有 1000 条随机路径规范化、42 个独立精确 `MatrixRank` 案例一致。随源码提供的精简 fixture 到 `L=12`；到 16 的数据可用 README 命令重新导出。
- 原 Mathematica 主计算从空目录运行到 `L=18`，三次结果与 Rust 一致。
- Rust 从空目录完整运行到 `L=22`，所有长度的四项计数均与 notebook 内置的独立对照表一致。生产实现不读该表。
- `L=18` 分别使用 1、4、16 个生成线程、不同批次大小、串行或并行消元，计数一致；固定批次大小时，消元操作次数也一致。详见 `thread-checks.json`。
- `cargo fmt --check` 与 `cargo clippy --all-targets --locked -- -D warnings` 通过。

## 速度

均从空结果目录开始，保留各自正常断点保存。Rust 使用 4 个生成线程，另有至多两个精确消元线程；Mathematica 使用 4 个实际子内核。

| 任务 | 原 Mathematica | 最终 Rust |
|---|---:|---:|
| 从零到 L=18，三次中位数 | 25.6330 s | 0.3395 s |
| 从零到 L=22，一次完整运行 | 未运行 | 55.5670 s |

`L=18` 该工作流的实测比值约为 **75.5 倍**。这是算法、数据结构、调度和保存策略一起改变后的结果，不是只替换语言的对照。原 Mathematica 使用原默认批次 10000 和方程缓存保存；Rust 默认批次 256，保存计数与消元断点，不保存全部原始方程。Mathematica 计时不含定义加载和子内核启动；Rust 外部计时包含进程启动、JSON 输出和断点保存；双方都不计 Rust 编译。

原 Mathematica 三次：24.105358、25.633045、25.652814 秒，保存在 `benchmark-m5-L18.json` 的 Mathematica 字段。该文件的 Rust 字段属于中间版本；最终 Rust 三次保存在 `benchmark-m5-L18-final.json`，上表采用最终版中位数。

`L=22` 最后一层计算约 51.96 秒，其中生成基 5.12 秒、SDE 7.99 秒、TrE 38.73 秒；完整运行的外部总耗时包含前面各层与保存。详见 `benchmark-m5-L22-final.json`。这一运行没有触发 BigInt 消元；大整数分支由独立测试覆盖。

剩余主要开销仍在 TrE/AllE 精确消元，主元依赖使其不能随意分成 16 份并行。CPU 不满并不等于线程设置无效；在目标 Linux 上应比较完成时间，不能从上述 M5 数字推算 14900HX 的速度。
