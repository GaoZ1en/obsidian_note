Python 面向对象编程练习：Person 与 Student
 - 目标：
	 - 理解和实践类的封装（Encapsulation）概念。
	 - 理解和实践类的继承（Inheritance）机制。
	 - 理解和实践多态（Polymorphism）的应用。
	 - 掌握 super() 函数在子类中调用父类方法的使用。

## 背景

我们生活在一个由各种“人”组成的世界里。学生是“人”的一种特殊类型。这个练习要求你定义一个基础的 Person 类和一个继承自 Person 的 Student 类，并通过它们来体现面向对象的核心概念。
- 要求：
	- 第一部分：定义 Person 类
		- 创建 Person 类：
		- 包含私有属性（使用 _ 或 __ 前缀）：_name (姓名) 和 _age (年龄)。
		- 封装：
			- 实现 __init__ 构造方法，接收 name 和 age 作为参数，并初始化对应的私有属性。
			- 提供公共的 getter 方法 get_name() 和 get_age() 来获取姓名和年龄。
			- 提供公共的 setter 方法 set_age(age) 来修改年龄，可以在方法中加入简单的验证逻辑（例如，年龄不能为负数）。姓名通常设定后不轻易改变，所以可以不提供 set_name 方法，或者提供一个但内部做一些限制。
			- 实现一个公共方法 display_info()，用于打印该人的姓名和年龄信息，格式例如：“Name: [name], Age: [age]“。
			- (可选) 实现 __str__ 方法，返回一个描述 Person 对象的字符串。
	- 第二部分：定义 Student 类
		- 创建 Student 类：
		- 继承： 使 Student 类继承自 Person 类。
		- 添加属性： 添加学生特有的私有属性：_student_id (学号) 和 _major (专业)。
		- 封装：
			- 实现 __init__ 构造方法，接收 name, age, student_id, major 作为参数。
			- 在 Student 的 __init__ 方法中，必须使用 super().__init__(name, age) 来调用父类 Person 的构造方法，以初始化继承自父类的 name 和 age 属性。
			- 初始化 Student 类自己特有的 _student_id 和 _major 属性。
			- 提供公共的 getter 方法 get_student_id() 和 get_major()。
		- 多态 (方法重写)：
			- 重写 (Override) 父类的 display_info() 方法。
			- Student 类的 display_info() 方法应该首先调用父类的 display_info() 方法（可以使用 super().display_info()）来打印姓名和年龄，然后接着打印学生特有的信息（学号和专业），格式例如：
　　```

　　Name: [name], Age: [age]

　　Student ID: [student_id], Major: [major]

　　```
	　　 - 添加一个学生特有的方法，例如 study(course_name)，打印 “[name] is studying [course_name].“。
	　　 - (可选) 重写 __str__ 方法，返回更详细的描述 Student 对象的字符串。
　　 - 第三部分：演示与测试
	　　 - 创建实例：
		　　 - 创建一个 Person 类的实例，例如 person1。
		　　 - 创建一个 Student 类的实例，例如 student1。
	　　 - 调用方法：
		　　 - 调用 person1 和 student1 的 get_name(), get_age() 等 getter 方法，并打印返回结果，验证封装性。
		　　 - 尝试调用 person1 的 set_age() 方法修改年龄，并再次调用 get_age() 验证。
		　　 - 调用 student1 的 get_student_id() 和 get_major() 方法。
		　　 - 调用 student1 的 study() 方法。
	　　 - 演示多态：
		　　 - 创建一个列表 people_list，包含 person1 和 student1 实例。
		　　 - 遍历 people_list，对列表中的每个对象（无论是 Person 还是 Student）调用 display_info() 方法。
	　　 - 观察并解释为什么调用同一个方法名 (display_info)，但 person1 和 student1 会产生不同的输出（这就是多态的表现）。
	　　 - 预期输出（示例）：
　　```

　　Getting info for person1:
　　Name: Alice
　　Age: 30
　　
　　Setting age for person1 to 31...
　　New age for person1: 31

　　Getting info for student1:
　　Name: Bob
　　Age: 20
　　Student ID: S12345
　　Major: Computer Science
　　Bob is studying Python Programming.

　　--- Demonstrating Polymorphism ---

　　Displaying info for object 1:
　　Name: Alice, Age: 31
　　
　　Displaying info for object 2:
　　Name: Bob, Age: 20
　　Student ID: S12345, Major: Computer Science
　　```
