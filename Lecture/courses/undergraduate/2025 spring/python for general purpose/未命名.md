题目一：学生成绩管理系统 (列表练习)

　　 - 背景： 假设你是一班的班长，需要记录同学们的分数。

　　 - 任务： 编写一个 Python 程序，实现以下功能：

　　 - 创建一个空列表，用于存储所有学生的分数。

　　 - 允许用户输入 班级里每位同学的分数（假设输入的分数为整数）。用户可以一直输入分数，直到输入一个特定的值（比如 -1）表示输入结束。

　　 - 输入结束后，程序需要完成以下操作：

　　 - 计算并输出 所有分数的总和。

　　 - 计算并输出 所有分数的平均值。

　　 - 找出并输出 最高分。

　　 - 找出并输出 最低分。

　　 - 统计并输出 有多少同学的分数超过了平均分。

```python
scores = []

while input != -1:
    score = int(input("请输入第一个学生的分数 (-1 结束): "))
    if score == -1:
        break
    scores.append(score)

# 计算总和
total = sum(scores)
print("所有分数的总和是:", total)

# 计算平均值
average = total / len(scores)
print("所有分数的平均值是:", average)

# 找出最高分
highest = max(scores)
print("最高分是:", highest)

# 找出最低分
lowest = min(scores)
print("最低分是:", lowest)

# 统计超过平均分的同学数量
for score in scores:
    if score > average:
        count += 1
print("有", count, "位同学的分数超过了平均分。")

# 另一种方法：使用 lambda 函数
# function = lambda x: x > average
# above_average_count = sum(map(function, scores))

```

　　题目二：简单的单词计数器 (字典练习)

　　 - 背景： 你想分析一段英文文本中每个单词出现的次数。

　　 - 任务： 编写一个 Python 程序，实现以下功能：

　　 - 定义一个字符串变量，包含一段英文文本（可以自己随意写一段）。

　　 - 将该文本中的所有单词分割开来。你可以假设单词之间用空格分隔，并且忽略标点符号（例如，可以将逗号、句号等替换为空格或者直接忽略）。

　　 - 创建一个空字典，用于存储每个单词及其出现的次数。

　　 - 遍历分割后的单词列表，对于每个单词：

　　 - 如果该单词已经在字典中作为键存在，则将其对应的值（计数）增加 1。

　　 - 如果该单词是第一次出现，则将其作为新的键添加到字典中，并将对应的值设置为 1。

　　 - 最后，遍历并输出 字典中每个单词及其出现的次数，按照 “单词: 次数“ 的格式输出。

```python
text = "This is a simple example. This example is simple."

## 替换标点符号
import string
translator = str.maketrans('', '', string.punctuation)
text = text.translate(translator)

words = text.split()

# 创建空字典
word_count = {}

# 遍历单词列表
for word in words:
    if word in word_count:
        word_count[word] += 1
    else:
        word_count[word] = 1

# 输出结果
for word, count in word_count.items():
    print(f"{word}: {count}")

```

　　- 题目二： 你会用到字符串的 split() 方法分割单词，字典的键值对操作（例如 in 关键字判断键是否存在，通过键访问和修改值）。你可能还需要处理文本中的标点符号，可以使用字符串的 replace() 方法或者其他方法。例如：
