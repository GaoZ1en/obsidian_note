# AGENTS.md — Lecture Courses

## Scope
Course notes organized by semester, course, notes, homework, and cheat sheets.

## Rules
- Preserve semester and instructor-based folder naming.
- Keep lecture notes in `notes/` and assignments in `homework/` when that structure already exists.
- Do not rename `cheat_sheet.md`, `cheat sheet.md`, or exam/problem files unless explicitly asked.
- New files should match the naming style already used in the target course folder.
- Course-local indexes or `README.md` files should be updated when a new lecture series or problem set is added.
