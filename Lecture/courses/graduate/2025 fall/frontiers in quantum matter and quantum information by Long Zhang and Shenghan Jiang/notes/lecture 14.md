a quantum code is represented as $\displaystyle{[[n,k,d]]}$, where $\displaystyle{n}$ is the number of physical qubits, $\displaystyle{k}$ is the number of logical qubits, and $\displaystyle{d}$ is the distance of the code.

the CSS code... the number of independent logical qubits is given by quotient space $\displaystyle{C_{1}/C_{2}}$, which is $\displaystyle{k}$, where $\displaystyle{C_{1}}$ is the classical linear code generated by the rows of $\displaystyle{H_{Z}}$, and $\displaystyle{C_{2}}$ is the classical linear code generated by the rows of $\displaystyle{H_{X}}$.

threshold theorem: if the error rate is below some threshold value $\displaystyle{p<p_{c}}$, then by increasing the number of physical qubits $\displaystyle{n}$, we can make the logical error rate $\displaystyle{p_{L}}$ arbitrarily small. but in practice, the threshold value $\displaystyle{p_{c}}$ is quite small (for example $\displaystyle{10^{-3}}$), and the number of physical qubits needed to achieve a reasonable logical error rate is quite large (for example $\displaystyle{10^{4}}$ physical qubits for each logical qubit). so it is still challenging to implement quantum error correction in practice.

error propagation: when we apply a quantum gate, the errors on the qubits can propagate to other qubits. for example, the CNOT gate can propagate bit-flip errors from the control qubit to the target qubit, and phase-flip errors from the target qubit to the control qubit. a principle for quantum error correction is transversal gates, which means error cannot propagate between qubits within the same code block. one physical qubit can only control one physical qubit in another code block...
