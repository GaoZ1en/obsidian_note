## 模拟卷 A 参考答案要点

### 题 1

$\rho(x,y) = \sqrt{d(x,y)}$。非负性、对称性显然。三角不等式：用 $(\sqrt{a} + \sqrt{b})^2 = a + b + 2\sqrt{ab} \ge a + b$（对 $a,b \ge 0$），且 $\sqrt{a+b} \le \sqrt{a} + \sqrt{b}$（$\sqrt{\cdot}$ 是凹函数）。由 $d(x,z) \le d(x,y) + d(y,z)$ 得
$$
\rho(x,z) = \sqrt{d(x,z)} \le \sqrt{d(x,y) + d(y,z)}
\le \sqrt{d(x,y)} + \sqrt{d(y,z)} = \rho(x,y) + \rho(y,z).
$$
故 $\rho$ 是度量 $\checkmark$。

### 题 2

1. $\varnothing \in \tau$ 显然；$X^c = \varnothing$（可数），故 $X \in \tau$。任意并：$(\bigcup U_\alpha)^c = \bigcap U_\alpha^c$，可数集的任意交仍可数。有限交：$(\bigcap_{i=1}^n U_i)^c = \bigcup_{i=1}^n U_i^c$，有限个可数集的并可数。故 $\tau$ 是拓扑（余可数拓扑）。

2. **不 Hausdorff**。任取两个非空开集 $U, V$，$U^c, V^c$ 均可数。则 $(U \cap V)^c = U^c \cup V^c$ 仍可数。由于 $X$ 不可数，$U \cap V \neq \varnothing$。故任何两非空开集均相交。

3. 在余可数拓扑下，$\mathbb{Q}$ 可数故为闭集，$\overline{\mathbb{Q}} = \mathbb{Q}$。$\mathbb{R} \setminus \mathbb{Q}$ 的补集为 $\mathbb{Q}$（可数），故无理数集为开集。

### 题 3

1. 球极投影：两个图册 $(U_N, \varphi_N)$、$(U_S, \varphi_S)$，转移函数 $v = u/\|u\|^2$，在 $\mathbb{R}^n \setminus \{0\}$ 上光滑。

2. $\mathbb{CP}^1 = \{[z^0 : z^1] \mid (z^0, z^1) \neq (0,0)\} / \mathbb{C}^\times$。取图册 $U_0 = \{[1:w]\}$，$\varphi_0 \mapsto w = z^1/z^0 \in \mathbb{C}$；$U_1 = \{[w:1]\}$，$\varphi_1 \mapsto w^{-1}$。转移函数 $w \mapsto 1/w$ 光滑。这与 $S^2$ 的球极投影图册（转移函数 $u \mapsto u/\|u\|^2$）结构一致。显式同胚：Hopf 映射的逆或直接 $[z^0 : z^1] \mapsto (2\operatorname{Re}(z^0 \bar{z}^1), 2\operatorname{Im}(z^0 \bar{z}^1), |z^0|^2 - |z^1|^2) / (|z^0|^2 + |z^1|^2)$。

### 题 4

1. $U(n)$：$U^\dagger U = I$ 给出 $n^2$ 个实约束（$U^\dagger U$ 的对角元 $n$ 个为 $1$，非对角元 $n(n-1)/2$ 个复数 $=0$，共 $n + n(n-1) = n^2$ 实约束），故 $\dim U(n) = 2n^2 - n^2 = n^2$。$U(n)$ 是 $GL(n,\mathbb{C})$ 的闭子群，且 $GL(n,\mathbb{C})$ 是李群，故 $U(n)$ 也是李群。

2. 利用 $(\mathbf{n} \cdot \boldsymbol{\sigma})^2 = I$：$e^{i\theta(\mathbf{n} \cdot \boldsymbol{\sigma})} = \sum \frac{(i\theta)^k}{k!}(\mathbf{n} \cdot \boldsymbol{\sigma})^k$。奇次项含 $\mathbf{n} \cdot \boldsymbol{\sigma}$，偶次项为 $I$ 乘以 $(-1)^{k/2}\theta^k/k!$。分离后即得 $\cos\theta + i\sin\theta(\mathbf{n} \cdot \boldsymbol{\sigma})$。几何意义：绕轴 $\mathbf{n}$ 旋转角度 $2\theta$ 的 $SU(2)$ 元素，给出 $SO(3)$ 的二重覆盖。

### 题 5

1. $X = x^1 \partial_2 - x^2 \partial_1$，$\omega = dx^1 \wedge dx^2$（为 $(0,2)$ 型反称张量）。
   $$
   \begin{aligned}
   (\mathcal{L}_X \omega)_{\mu\nu}
   &= X^\lambda \partial_\lambda \omega_{\mu\nu}
   + \omega_{\lambda\nu} \partial_\mu X^\lambda
   + \omega_{\mu\lambda} \partial_\nu X^\lambda.
   \end{aligned}
   $$
   $\omega_{12} = 1$，$\omega_{21} = -1$，其余为零。$\partial_\mu X^\lambda$ 项：唯一非零的为 $\partial_2 X^1 = 1$、$\partial_1 X^2 = -1$。代入后所有贡献抵消，得 $\mathcal{L}_X \omega = 0$。

2. Cartan：$d\omega = d(dx^1 \wedge dx^2) = 0$。$i_X \omega = x^1 dx^2 + x^2 dx^1$（注意符号：$i_{\partial_1} dx^1 = 1$ 等）。$d(i_X \omega) = dx^1 \wedge dx^2 - dx^2 \wedge dx^1 = 2 dx^1 \wedge dx^2$？等一下——
   实际：$i_X(dx^1 \wedge dx^2) = X^1 dx^2 - X^2 dx^1 = -x^2 dx^2 - x^1 dx^1$……让我小心重算。
   $i_X(dx^1 \wedge dx^2) = (i_X dx^1) \wedge dx^2 - dx^1 \wedge (i_X dx^2) = X^1 dx^2 - X^2 dx^1 = -x^2 dx^2 - x^1 dx^1$？
   Wait: $X^1 = 0$。$X = (0, x^1, 0) - (x^2, 0, 0)$。在 $(x^1,x^2)$ 平面上 $X = (-x^2, x^1)$。故 $i_X(dx^1 \wedge dx^2) = -x^2 dx^2$... 不，$i_X(dx^1 \wedge dx^2) = X^1 dx^2 - X^2 dx^1$。
   $X^1 = -x^2$，$X^2 = x^1$。故 $i_X \omega = -x^2 dx^2 - x^1 dx^1$？
   等下——$X^1$ 是 $\partial_1$ 方向的分量，来源于 $-x^2 \partial_1$，故 $X^1 = -x^2$，$X^2 = x^1$。所以
   $i_X(dx^1 \wedge dx^2) = (-x^2)dx^2 - x^1 dx^1$。嗯这是对的。
   $d(i_X \omega) = -dx^2 \wedge dx^2 - dx^1 \wedge dx^1 - (-x^2) d(dx^2) - x^1 d(dx^1)$，但 $d(dx^i) = 0$ 且 $dx^i \wedge dx^i = 0$，故 $d(i_X \omega) = 0$。
   且 $d\omega = 0$（$\omega$ 是常系数 2-形式）。故 $\mathcal{L}_X \omega = i_X(0) + d(i_X \omega) = 0$。$\checkmark$

   等一下上面有计算错误。让我再算一遍：
   $X = x^1 \partial_2 - x^2 \partial_1$。系数：$X^1 = -x^2$，$X^2 = x^1$，$X^3 = 0$。
   $i_X(dx^1 \wedge dx^2) = (i_X dx^1) \wedge dx^2 - dx^1 \wedge (i_X dx^2)$
   $= X^1 dx^2 - dx^1 X^2 = -x^2 dx^2 - x^1 dx^1$。
   Wait, $X^1 dx^2 = -x^2 dx^2$, and $-dx^1 X^2 = -x^1 dx^1$. So $i_X\omega = -x^2 dx^2 - x^1 dx^1$.
   $d(i_X\omega) = -dx^2 \wedge dx^2 - dx^1 \wedge dx^1 = 0$.
   So $\mathcal{L}_X \omega = 0$. ✓

3. 几何解释：$X$ 是绕 $x^3$ 轴的无穷小旋转。2-形式 $\omega = dx^1 \wedge dx^2$ 是 $x^1x^2$ 平面的面积形式，绕 $x^3$ 轴旋转保持该平面不变，故 Lie 导数为零。

### 题 6

证法见 [[微分几何与拓扑工具手册]] 第六、七节。

### 题 7

1. $T^2$：$H_0 \cong \mathbb{Z}$，$H_1 \cong \mathbb{Z}^2$，$H_2 \cong \mathbb{Z}$。
2. Klein 瓶：$H_0 \cong \mathbb{Z}$，$H_1 \cong \mathbb{Z} \oplus \mathbb{Z}_2$，$H_2 \cong 0$。
3. $\mathbb{RP}^2 \vee S^2$：wedge sum 的同调为各自奇异同调的直和（除 $H_0$ 外）。$H_0 \cong \mathbb{Z}$，$H_1 \cong H_1(\mathbb{RP}^2) \oplus H_1(S^2) \cong \mathbb{Z}_2 \oplus 0 \cong \mathbb{Z}_2$，$H_2 \cong H_2(\mathbb{RP}^2) \oplus H_2(S^2) \cong 0 \oplus \mathbb{Z} \cong \mathbb{Z}$。

## 模拟卷 B 参考答案要点

### 题 1

1. $\tau_1$ 比 $\tau_2$ 强（细）若 $\tau_2 \subseteq \tau_1$。两者不可比较若 $\tau_1 \not\subseteq \tau_2$ 且 $\tau_2 \not\subseteq \tau_1$。

2. $\operatorname{Id}_\mathbb{R}: \mathbb{R}_{\tau_\ell} \to \mathbb{R}_{\tau_E}$ 连续。证明：需验证每个 $E$-开集的原像为下限开集。对 $(a,b) \in \tau_E$，$(a,b) = \bigcup_{n} [a+1/n, b)$ 为下限开集的并 $\in \tau_\ell$。一般开集是开区间的并，原像亦然。故 $\tau_\ell$ 比 $\tau_E$ 强，恒等映射连续。

### 题 2

1. $f(x) = x/(1-\|x\|)$，$g(y) = y/(1+\|y\|)$。互为逆，均连续。

2. 角坐标：$f(e^{i\theta}) = e^{in\theta}$，$f_*(\partial_\theta) = n \partial_\phi$（其中 $\phi$ 为像的角坐标）。$f$ 为微分同胚 $\iff n = \pm 1$（此时 $f_*$ 为同构）。

### 题 3

1. $d\omega = d\bigl(\frac{x\,dy - y\,dx}{x^2+y^2}\bigr) = \frac{\partial}{\partial x}\bigl(\frac{x}{x^2+y^2}\bigr) dx \wedge dy + \frac{\partial}{\partial y}\bigl(\frac{-y}{x^2+y^2}\bigr) dx \wedge dy$。计算得零（这是 $\mathbb{R}^2\setminus\{0\}$ 上的经典闭非恰当形式）。

2. $i_X \omega = \frac{x\cdot x + y\cdot y}{x^2+y^2} = 1$。 $\mathcal{L}_X \omega = i_X d\omega + d i_X \omega = 0 + d(1) = 0$。故 $\omega$ 是 $X$-不变的。

3. $\omega$ 在 $M$ 上不恰当。沿环绕原点的闭路 $S^1$：$\oint_{S^1} \omega = 2\pi \neq 0$。若 $\omega = df$，则有界区域上积分为零。故 $[\omega] \neq 0 \in H^1_{\mathrm{dR}}(M)$。

### 题 4

1. $i_{X_H} \omega = -dH$，$i_{X_F} \omega = -dF$。

2. $\omega(X_H, X_F) = (i_{X_H} \omega)(X_F) = (-dH)(X_F) = -X_F[H] = -\{F,H\} = \{H,F\}$（取决于 Poisson 括号的符号约定。标准约定 $\{H,F\} = X_F[H]$ 或 $\{H,F\} = \omega(X_H, X_F)$）。

3. $i_{[X_H, X_F]} \omega = \mathcal{L}_{X_H} i_{X_F} \omega - i_{X_F} \mathcal{L}_{X_H} \omega = -d\mathcal{L}_{X_H} F = -d\{H,F\}$？需要展开。标准的证明利用 Cartan 公式：
   $$
   i_{[X_H, X_F]} \omega = [\mathcal{L}_{X_H}, i_{X_F}] \omega = \mathcal{L}_{X_H} i_{X_F} \omega - i_{X_F} \mathcal{L}_{X_H} \omega.
   $$
   $\mathcal{L}_{X_H} i_{X_F} \omega = \mathcal{L}_{X_H}(-dF) = -d(\mathcal{L}_{X_H} F) = -d\{H,F\}$。
   $i_{X_F} \mathcal{L}_{X_H} \omega = i_{X_F}(0) = 0$（$\omega$ 闭，且 $\mathcal{L}_{X_H} \omega = 0$ 是因为 $i_{X_H} d\omega + d i_{X_H} \omega = 0 + d(-dH) = 0$？不完全是……$i_{X_H}\omega = -dH$。所以 $\mathcal{L}_{X_H} \omega = i_{X_H} d\omega + d i_{X_H} \omega = 0 - d^2 H = 0$。对）。
   故 $i_{[X_H, X_F]} \omega = -d\{H,F\}$，即 $[X_H, X_F] = X_{\{H,F\}}$。

### 题 5

1. $*(dx^1 \wedge dx^2) = dx^3 \wedge dx^4$，$*(dx^1 \wedge dx^3) = -dx^2 \wedge dx^4$ 等。用循环排列记忆。

2. 6 维 2-形式空间。自对偶基（3 维）：$dx^1 \wedge dx^2 + dx^3 \wedge dx^4$，$dx^1 \wedge dx^3 + dx^4 \wedge dx^2$，$dx^1 \wedge dx^4 + dx^2 \wedge dx^3$。反自对偶基（3 维）：各和改为差。总维数 $3+3=6$。

3. $m=4, q=2$：$(-1)^{2(4-2)} = (-1)^4 = 1$。故 $**\omega = \omega$。$\checkmark$

### 题 6

1. 用性质 4，$k=3$（缩并 3 对指标）：$\epsilon^{\mu\nu\rho\sigma} \epsilon_{\mu\nu\rho\tau} = 3! \delta^\sigma_\tau = 6\delta^\sigma_\tau$。

2. $\epsilon_{\mu\nu\rho\lambda} \epsilon_{\alpha\beta\gamma\lambda} = \delta^{\mu\nu\rho}_{\alpha\beta\gamma}$（性质 3 的变体，缩并一个指标时）。展开为：
   $$
   \delta^\mu_\alpha \delta^\nu_\beta \delta^\rho_\gamma + \delta^\mu_\beta \delta^\nu_\gamma \delta^\rho_\alpha + \delta^\mu_\gamma \delta^\nu_\alpha \delta^\rho_\beta
   - \delta^\mu_\alpha \delta^\nu_\gamma \delta^\rho_\beta - \delta^\mu_\beta \delta^\nu_\alpha \delta^\rho_\gamma - \delta^\mu_\gamma \delta^\nu_\beta \delta^\rho_\alpha.
   $$

3. $\epsilon^{\mu\nu\rho\sigma} \epsilon_{\mu\nu\rho\sigma} = 4! = 24$。

### 题 7

1. Möbius 带同伦等价于 $S^1$。$H_0 \cong \mathbb{Z}$，$H_1 \cong \mathbb{Z}$，$H_2 \cong 0$。$H_2 = 0$ 因为 Möbius 带不可定向且边界非空（不是闭链）。

2. $\Sigma_2 = \Sigma_1 \# \Sigma_1$。用 Mayer-Vietoris 将 $\Sigma_2$ 分解为两个穿孔环面沿 $S^1$ 粘合。$H_0 \cong \mathbb{Z}$，$H_1 \cong \mathbb{Z}^4$（四个生成元），$H_2 \cong \mathbb{Z}$（基本类）。一般的 $H_1(\Sigma_g) \cong \mathbb{Z}^{2g}$。

### 题 8

1. 直接验证（见题 3）。

2. $M$ 同伦等价于 $S^1$（$\mathbb{R}^3 \setminus \{z\text{-轴}\} \simeq S^1$）。可取 deformation retraction $(x,y,z) \mapsto (x/\sqrt{x^2+y^2}, y/\sqrt{x^2+y^2}, 0)$。故 $H^1_{\mathrm{dR}}(M) \cong H^1_{\mathrm{dR}}(S^1) \cong \mathbb{R}$。

3. $\eta$ 不是全微分（$\oint_{S^1} \eta = 2\pi \neq 0$）。$[\eta]$ 是 $H^1_{\mathrm{dR}}(M) \cong \mathbb{R}$ 的生成元。
