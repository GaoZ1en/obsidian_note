# Verification scripts

Run from the project root:

```text
wolframscript -file scripts/spin0_and_spin2_checks.wl
```

The script checks exact algebraic identities for the projector, nonlinear
Raychaudhuri solution, spin-0 pullback/curl, endpoint-complete change between
the $\kappa$ and $\kappa+\theta$ representatives, and one unimodular spin-2
chart.

A passing result is not evidence for outer-joint cancellation, existence of a
vacuum development, the Damour/cross-focusing constraints, nondegeneracy,
completeness, positivity, surjectivity, continuum topology, or a reduced
action.
