# Verification scripts

Run from the project root:

```text
wolframscript -file scripts/spin0_and_spin2_checks.wl
```

The script checks exact algebraic identities for the projector, nonlinear
Raychaudhuri solution, spin-0 pullback/curl, conversion to initial/outer areas,
initial endpoint-plus-joint cancellation, endpoint-complete change between the
$\kappa$ and $\kappa+\theta$ representatives, extended/fixed-port rank and
kernel, sheetwise affine composition, and both the tensor and full-density
forms of one unimodular spin-2 chart.

A passing result is not evidence that the spin-0 truncation is preserved by
transverse vacuum evolution, that a generic CIVP has an extra corner
compatibility condition, or that Stage 2 is reduced.  It also does not prove a
full gravitational gauge quotient, completeness, positivity, surjectivity,
continuum topology, or a reduced action.
