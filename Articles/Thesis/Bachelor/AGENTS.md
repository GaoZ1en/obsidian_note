# AGENTS.md — Bachelor Thesis

## Scope

Structured thesis workspace with sections, appendices, abstract, and acknowledgements.

## Rules

- Preserve thesis file boundaries: sections stay separate from appendices.
- Keep naming in the existing thesis style (`section N ...`, `Appendix X ...`).
- Do not reorder thesis sections or appendices without explicit instruction.
- Prefer incremental edits to individual chapter files over broad rewrites.
- Update `README.md` if thesis structure changes.
