# Electric Field in AdS3

Quantization of Maxwell electric-field modes in global AdS3.

## Article draft

| File | Description |
|---|---|
| `article/1_model.md` | Maxwell action, mode-selection falloffs, equations of motion, and symplectic form |
| `article/2_mode_solutions.md` | Normalizable mode solutions in temporal gauge and in the dual scalar field-strength basis |
| `article/3_quantization.md` | Temporal-gauge mode expansion, symplectic normalization, oscillator algebra, and zero-mode treatment |
| `article/4_euclidean_green_function.md` | Euclidean two-point function from temporal-gauge mode sums |
| `article/appendix_a_falloffs_and_variational_principle.md` | Falloff estimates, off-shell variation checks, and variational principle |
| `article/appendix_b_gauge_fixing_and_zero_modes.md` | Temporal gauge reachability, residual gauge fixing, and static pure-gauge modes |
| `article/texfiles/` | LaTeX source organized with `main.tex`, shared preamble files, and section data files |
