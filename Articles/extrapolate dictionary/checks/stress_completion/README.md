# Executed checks for the causal switched reconstruction

This directory accompanies [Genuine switching and the first gravitational
reconstruction](../../half_bps_stress_completion.md). All programs were newly
executed for this addition. The existing Mathematica/xAct programs elsewhere
in the project were inspected as earlier evidence; they were not rerun or
used as expected-result inputs here.

## Reproduce

The executed environment was Python 3.12.14, SymPy 1.14.0, NumPy 2.3.5,
SciPy 1.17.0 and mpmath 1.3.0. With these packages available, run from this
directory:

```bash
python3 run_checks.py
```

The driver executes the listed programs, records their exit codes, captures
their actual output, and hashes each executed source and result. It writes
[execution_record.json](execution_record.json). The individual JSON records
are regenerated by their corresponding scripts. No pre-existing JSON result
can make an unsuccessful program count as a successful run.

The mathematical starting version was
`ba8a9a5161a538c0d1addf7215c20cf64f4ddb79`. The PR also preserves a later
upstream commit affecting a different research directory. The source
conventions in the audited extrapolate directory were unchanged by that
upstream commit.

## What the computations establish

The symbolic checks establish algebraic identities under the assumptions
declared in their programs: signatures, masses, tensor conventions,
radial Green normalization, and source coefficients. The independent
linearized Einstein program constructs the background connection and
varies the curvature directly, rather than substituting a claimed TT
equation as an expected identity.

The numerical integrations test independently represented functions in
nonsingular domains or explicitly paired scalar distributions. In
particular, the massive mismatch check differentiates an already integrated
scalar seed; it does not numerically integrate a bare nonintegrable
`lambda**(-5/2)` threshold function. The random Gram samples are supplementary
checks of a separately proved inequality.

The arbitrary-test-function and uniform-limit statements rely on the
written causal-support, Hankel-transform, parameter-family and dyadic
estimates. A finite CAS or quadrature run is not substituted for any of
those steps.

## Cross-checks and corrections retained in the proofs

- The output retarded kernel is paired before radial cutoff removal. Its
  causal six-dimensional support provides the required large-radius decay.
- Transverse injection is integrated as a parameter. The proof does not
  infer its shrinking support volume from an unrelated joint distribution
  supremum norm.
- Large plus-injection tails are separated from the mass-preserving chart
  and controlled by the full tempered kernel.
- Exact all-insertion mass support is used after the common radial cutoff
  is removed. The finite-cutoff estimates apply to explicitly localized
  families and do not assume that support prematurely.
- Radial mass differentiation retains its external-null jets. The explicit
  positive-mass-origin jet includes a nonzero contact; it is fixed by the
  original radial integral.
- The causal TT response and a bare time-step-times-mode-commutator response
  differ by nonzero massless constraint terms. The source bridge defines
  and verifies the complete projected response.
- A compact radial vertex source need not give a decaying non-TT FG metric.
  Its polynomial constraint tail has zero current-order endpoint cross flux
  on the specified dense gapped wave-packet domain. The proof uses radial
  nonstationary phase; it does not infer a global interacting operator
  domain from Hilbert-space density.
- The CFT shell pushforward's critical set includes configurations with just
  one parallel pair. Their zero measure, not an incorrect all-three-parallel
  criterion, is used in the coarea argument.
- An arbitrary-power radial cutoff rate uses a plateau profile. General
  bounded pointwise profiles still give the stated strong convergence.

**Verified:** the executions indexed above, their recorded source/result
hashes, the stated finite identities and numerical comparisons.

**Assumptions:** the package versions or compatible implementations, the
explicit domains in each symbolic calculation, and the analytic hypotheses
listed in the accompanying notes.

**Not verified by these programs:** arbitrary-test-function convergence,
interacting positivity, arbitrary joint infrared-cutoff paths, or equality
of independently chosen Abel and Gram prescriptions. The main report states
the proved distribution theorem and its precise order of limits.
