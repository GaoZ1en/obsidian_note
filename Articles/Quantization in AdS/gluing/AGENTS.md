# AGENTS.md — Regional Observable Gluing

- Start from independently defined regional and global observable algebras.
- Derive regional dynamics and interface data from the regional actions or CPS; do not define gluing by a state, mode expansion, or regulator.
- Specify the interface type and its admissible data before constructing the regional objects.
- Keep the common interface data prescribed in each region, then release it in the sum of the regional actions.
- Derive continuity, oriented flux or transmission matching, and gauge constraints from this release.
- Build each regional observable algebra from regional data only, including any response, transport, charge, or boundary information needed for composition.
- Define the sewing relation or reduction on the product of the regional objects and construct the induced map to the independently defined global algebra.
- Determine the sewing map's domain, kernel, image, exactness, and associativity rather than assuming a tensor-product identification.
- In gauge theory, quotient based proper gauge while retaining the active cut action, interface charge sectors, transition data, electric flux, and crossing Wilson generators.
- Treat timelike, null, and spacelike interfaces through their own boundary-history, characteristic, or Cauchy-data problems.
- Keep state restriction, representation choice, mode expansion, partial trace, KMS, and entropy downstream of observable-algebra sewing.
