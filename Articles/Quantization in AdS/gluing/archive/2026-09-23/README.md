## 使用方法

- 顺着编号读研究思路的转变；各阶段 INDEX 列出本阶段所有原笔记。
- 横向查 scalar、gauge、null 或 representation，使用[主题索引](../../TOPICS.md)。
- 查看原项目组织方式，使用[归档前 README](07-retirement-and-project-records/previous-layout/README.md)和[TODO](07-retirement-and-project-records/previous-layout/TODO.md)。
- 查询原路径与当前路径，使用[迁移清单](../manifest.json)及[归档核对](../README.md)。

跨阶段材料按主要问题归类，不把后来的更新日期当作新阶段的唯一依据。旧文中的 active／current／next actions 属于历史语境。原有缺失引用保持缺失，不通过猜测替换成另一个 formalism。
