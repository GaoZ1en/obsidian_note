# 输入依赖表：删字段不删物理目标

I＝独立信息；D＝派生结构；C＝实现选择；X＝下游扩张。作用在 I 上的模型/证明范围条件不等于 C：改变质量、几何、群或真实 wall 参数一般改变物理理论。同一原审计行可能混合多个类别，不将整行误称独立最小输入。存在性、唯一性、连续性、kernel、onto、coherence 是证明义务，不是第五种可付费输入。

独立信息是相对于本次保留记录及指定输出/等价关系而言。只有遗忘后存在两份合法实例，其剩余输入完全相同而指定输出不同，才称该遗忘丢信息。派生缓存删除只在下列方法成立时允许；不能用“可重算”掩盖尚未证明的域或算法。

## 实际从 constructor 删去的字段及恢复方法

| 拟删字段／重复内容 | 重建方法 | 成立条件及不能一并删除的内容 |
|---|---|---|
| 独立 $\mathfrak A_B/\mathcal A_B$ 字段 | 由 action、实际 labels/products/domain 与真实评价零关系构造 | 只在该 algebra 已证明存在的模型；不是从任意 action 自动量子化 |
| 独立 $\mathcal R_B/\mathfrak R$ 字段 | 从区域 action/domain 定义全源关系；R1 的 lift+因果 inverse 在已证明域求解 | 关系可多值；source labels、真实 B、joint domain 不删；solver 有效性仍待模型验收 |
| $G,H,\rho,D$ 各自缓存 | 相同源构造后取 actual traces；合法纯块子域用 Green identity | 不把联合域当直积；不把有限核采样值当完整 Green distribution |
| 非特征 on-shell 高阶 normal jets | R2 的 PDE 递推，从场和第一 conormal 恢复 | 同一跨面 smooth PDE/source；不适用于 null 或 off-shell test kernels |
| 双 null mixed corner jets | $a_{r+1,s+1}=f_{rs}/4-m^2a_{rs}/4$ | 两张完整 traces 与共同 corner 值已给；纯方向 trace 本身不删 |
| 已由第二 sheet/wall 决定的 transverse seeds | 取另一张完整 trace 的 corner derivatives，或解实际 wall+transport 关系 | 仅删确已确定部分；一个 corner 的无限 Taylor 序列不能取代完整 smooth trace |
| 独立 Gauss/conormal 方程清单 | 变分完整 action、源耦合及真实 boundary/interface action | 必须仍实际实施这些导出约束；含 matter/topological 项时一并变分 |
| $\Theta,\Omega$ 数值/公式缓存 | 按原相对 $(L,\ell,\theta,C)$ 规则和实际 transition 运输重算 | 不删尚未由规则固定的边界辛结构；允许同步 exact 改进，不要求 Θ 守恒 |
| 每点 stabilizer 列表 | 解实际 $g\cdot\phi=\phi$，参数需遵守 B、anchors、branch 政策 | 完整 fields/gauge action 不能删；不假设所有点同一维数 |
| label null ideal 缓存 | 用完整 field evaluation 算全部恒零 labels；Maxwell 为 $f=0,P_Tg=0$ | 线性及 polynomial 完整性需证明；物理中心不等于恒零；不删除 gauge fields |
| Gram 矩阵缓存 | 已给实际 C 时计算 $G(v,w)=\langle Cv,Cw\rangle$ | 若 G 是独立 source pairing 而 C 尚未构造，不能倒过来假定 C 存在 |
| 已由 quantum realization 给出的 F/R/cups | 用实际 normalized intertwiners/inner products 计算 overlap/composition | 全 realization 已固定；只知 fusion dimensions 不足；basis change 全部 maps 同步 |
| 某份 particular solution | 换 representative 并同步平移 affine labels/常数项 | 完整 source tuple 与 fluctuation theory 相同；不同物理 source 不当作 choice |
| 某份 off-shell lift/collar extension | 换另一合法 lift；R1 右逆恒等式消去解差，规范模型保留实际 comparison arrows | lift 必须实现全部原数据；raw global field 可能只由 proper 联系，不称逐点相同 |
| 特定模基/reference connection | 完整基变换或 $a'=a+A_0-A'_0$，同步运输 labels | 不截断、不丢 harmonic/gauge directions；不声称全局 gauge section 存在 |
| 已关闭 seam 的永久 ports/全部 binary 历史 | 从完整输出 action、B、bundle、gauge policy 重新 opening | 输出的 global twist/branch/retained defect 必須还在；不是只存 reduced algebra |
| 每条纯 regrouping 的 associator 缓存 | actual comparison maps 已构造后计算 $\Theta_Q^{-1}\Theta_P$ | 不以该公式假设 maps 存在；physical braid/twist 与同几何 regrouping 分开 |

## 不删除的独立信息和下游目标

实际几何/全局丛与群、完整 action 的归一化、尚未由 action/变分域唯一指定的真实 B、source pairing、closing/removal 操作、真实 identification/anchors、完整规范作用及离散 proper 政策、预先固定的 observable target/准入域仍须在记录中。它们之间也可能重复编码；只有证明可恢复时才再压缩，不能一边保留含 level 的 action 一边用改变 level 当“其余输入相同”。

表示、公用算符域/character、复合场重整化、charged-channel realization、state preparation/cross correlations、amplitude pairing/phase lift，仅对所要求的下游目标追加。没有从模型目录删除这些目标；未完成项见 `repair_proofs.md` 最后一节。
