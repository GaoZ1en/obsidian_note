The gravity–U(1) calculation uses a smooth disk with trivial holonomy and no extra boundary fields. It establishes zero mixed class for the unchanged geometric AdS vacuum under its stated symmetry assumptions. It does not classify punctured, BTZ, or general mixed-boundary theories.
