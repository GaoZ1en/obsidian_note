# Independent vacuum-orbit review checks

Review base: `4fb3d286505cec4503e6901d133f5402d434b345`.
Tested with Python 3.13.5 and SymPy 1.14.0. No Wolfram, xAct, or network access is required by these scripts.

Run from this directory:

```sh
python -m pip install sympy==1.14.0
python verify_classical.py
python verify_hill.py
python verify_gauge.py
python verify_quantum.py --level 10 --u 0
python verify_quantum.py --level 10 --u 1
python audit_quantum.py
```

The quantum script writes exact rational coefficient tables, coefficientwise expansions through c^-4, and resumable checkpoints to this directory. The audit requires the two level-10 tables. Use --seed only with a table/checkpoint from the same u and a lower complete level. Tables use descending positive partitions J; the operator word is H_{-I} H_{j_s}...H_{j_1}. The u=-1 table is generated by taking the adjoint of the u=1 table.

## Executed results

- 180 exact rational Hamiltonian-identity checks through kappa^3, including p=-1,0,1. All intermediate Witt modes are retained. X_0 is exactly linear to the checked order.
- 16 Hill/Schur checks through epsilon^4 for a two-harmonic finite diffeomorphism, plus the single-high-pair quartic coefficient.
- Covector gauge identity, radial/tangential indicial coefficients, and the full axial equation by independent component calculation.
- 1020 comparisons with the previous c^-1 and c^-2 normal-symbol kernels; all match.
- 154 exact PBW commutator tests on input levels through 8, retaining intermediate grades.
- Exact normal coefficients: H_0 has 299 nonzero terms through input level 10; H_1 has 196 through input level 10; the adjoint H_-1 table has 196 through output level 10 (input level at most 9).

The attached review archive contains the executed JSON outputs; the repository keeps the generating scripts and this result record rather than the bulky generated tables. Coefficientwise c^-4 is not a uniform operator expansion. The normal series at fixed c>1 is locally finite on the algebraic finite-energy domain.

## Boundaries

These checks start from the vacuum CPS cocycle given in the original note. They do not independently re-evaluate the complete bulk/boundary/corner CPS integral, establish linearized completeness, prove the reflecting AdS initial-boundary-value theorem, or construct the full renormalized quantum moment map from a prescribed CPS/Wick symbol. Finite tests do not replace those proofs. The pre-review main note is archived byte-for-byte; the sourced de Donder note itself is unchanged.
