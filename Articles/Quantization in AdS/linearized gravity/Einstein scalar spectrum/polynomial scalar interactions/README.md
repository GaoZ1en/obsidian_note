## 已经得到的结果

本研究沿固定背景 φ⁴ 材料推进到一般 normal-ordered φⁿ，采用 −λₙφⁿ/n!、Δ>1、standard quantization。它不是引力研究包的改写，也不使用引力交换作为输入。

1. **一般 n 的完整一阶有限块**：从 KG 模、有限 Beta 和、Wick/Bose 因子出发，自动列举同一 (E,J) 的所有粒子数，保存矩阵、物理 Gram、代数特征根和本征空间。
2. **共振存在性分类**：所有 1↔(n−1) 共振积分为零；两侧各至少两条腿时，算术条件允许的通道有严格非零例。φ⁶ 在整数 Δ 可以改变粒子数，φ³ 首阶恒为零，φ⁵ 在偶整数 Δ 有真正首阶 splitting。
3. **一般 k 的最小粒子数解析谱**：φ²ᵏ 在恰好 k 粒子的保持数作用中，每个 scalar-primary module 只有一个活跃方向，系数完全求出。φ⁶ 三体高激发正谱趋于 1/(96π²)，不再像 φ⁴ 那样衰减。
4. **手征多体核与非零谱**：核恰为 k 重合消失理想；应用已发表 Jack/character 定理得到全 N 计数、首个零模次数及显式态。N=k+1 的全部手征非零谱可解，另有全 N 的两个低次 primary 谱族。
5. **完整正性分类与第一个负谱块**：对 λ₂ₖ>0，所有完整块均半正定，当且仅当没有改变 N 的共振。若 Δ=a/b 最简且 b≤k−2，第一个负谱块恰为 E*=(k+b)Δ、J=0，恰有一个负根；其全部非零谱和分子 parity 所决定的附加谱族已求出。φ⁶、Δ=2 的九维例是这一全指标定理的最小例。
6. **φ³ 实质二阶谱**：真空归零、物理 gap 固定后，所有 Δ>1 的二阶共振作用保持 N，是精确二体交换的 pair lift；一般质量的有限矩阵用收敛 5F4 表示。全 Δ ground binding 严格负；Δ=2 的全部 pair-primary 谱已作全指标证明。
7. **二阶精确算术结构**：B 基中剥去 λ₃²/(8π)，偶整数 Δ 的矩阵有理，半奇整数 Δ 为 A₀+πA₁，奇整数 Δ 为 A₀+ζ(3)A₁；A₀,A₁ 均为有理矩阵。已有 Δ=3/2、3 的完整非截断谱例。

8. **N=k+1 的全非手征秩与压缩**：k≥3、所有 Δ>1，令 m=min(P,Q)、J=|P−Q|，primary rank 在 ground grade 为 1，非 ground 的 J≤1 时为 m，J≥2 时为 m+1。全部正谱来自 (m+1) 阶 Racah Gram；显式非手征零模一般不受跨 N 共振保护。
9. **任意固定层的大 N 完整谱**：保持数作用在 λ₂ₖ=gN¹⁻ᵏ 下有明确的 additive occupation limit，primary/descendant 重数随之确定；误差 O(N⁻¹ᐟ²) 有真正取到的反例。φ⁴ 有统一 primary defect gap，而 k≥3 的全层 defect 点谱稠密；不等于总 AdS 能谱连续。
10. **完整共振的大 N 修正**：所有允许改变 N 的偶次顶角均驱动 O(g√N) 线性模式，故全基态不是 stationary condensate；中心化基态谱测度有严格高斯极限。φ⁶、Δ=2 另有精确全 N 方差和完整 quadratic correction。
11. **φ⁵ 与一般奇次的二阶推进**：明确证明 φ⁵ 必须额外指定有限 quartic matching；求出 Δ=4/3 的普适四体量。对每个奇数 n，在 Δ=(n−1)/(n−2) 证明有限、严格负的最高 (n−1) 体二阶量，并核查完整 ground 简并块。

这些结论区分了解析定理、独立推导、后续协作复核和有限机器证据。任意 N>k+1 的非手征核、一般共同增长极限与高阶余项仍未完成。
