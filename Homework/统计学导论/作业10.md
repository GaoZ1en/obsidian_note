	2. 极大似然估计. 定义似然函数 $\displaystyle{L(\lambda|X)=\prod_{i=1}^{32}P(X_{i}=k_{i}|\lambda)=\frac{e^{-32\lambda}\lambda^{64}}{(k_{1})!(k_{2})!\dots(k_{32})!}}$. 其中$\displaystyle{\sum^{32}_{i=1}k_{i}=64}$. 令$\displaystyle{\frac{\mathrm{d}\ln L}{\mathrm{d}\lambda}=-32+\frac{64}{\lambda}=0}$, 解得$\displaystyle{\lambda=2}$.
	3. 极大似然估计的R语言实现
```R
	# 定义待优化函数
log_likelihood <- function(lambda, k, n) {
  return((n * lambda - sum(k) * log(lambda))) # 对数似然
}

# 已知数据
k_total <- 64
n_hours <- 32 

# 使用 optimize 函数优化参数
result <- optimize(log_likelihood, c(0.001, 10), k = k_total, n = n_hours)

# 获取估计的参数值
lambda_hat <- result$minimum
lambda_hat
```

	1. 不能说 $\displaystyle{a\in(2.5,2.8)}$ 的概率为 0.99. 正确的表述应该是：“在许多独立的抽样中，约有 99% 的置信区间将包含真实参数 $\displaystyle{a}$。”或者说：“我们有 99% 的信心认为$\displaystyle{a}$在区间 $\displaystyle{(2.5,2.8)}$ 内。”置信区间的理解是基于点估计的统计不确定性，强调的是方法的可靠性，而不是某个具体参数的概率。
