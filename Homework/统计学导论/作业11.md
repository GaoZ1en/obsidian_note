1. 若$\displaystyle{X\sim N(\mu,1)}$, $\displaystyle{X_{1},\dots,X_{n}}$为$\displaystyle{X}$的重复观测样本。对于假设检验问题

$$\tag{1.1}
\begin{align}
H_{0}:\mu\geqslant 0
\end{align}
$$

若用样本均值$\displaystyle{\bar{X}}$作为检验统计量，取

$$\tag{1.2}
\begin{align}
\mathbb{D} & =\left\{x:1<x<1.05\right\}
\end{align}
$$

计算 $\displaystyle{\mathbb{P}_{H_{0}}\left\{\bar{X}\in \mathbb{D}\right\}}$. 进一步$\displaystyle{\mathbb{D}}$可以作为检验的拒绝域吗？若用$\displaystyle{\mathbb{D}}$作为拒绝域得到的检验结果是拒绝原假设，我们可以认为原假设不成立吗？

我们知道$\displaystyle{\bar{X}\sim N\left( \mu, \frac{1}{n} \right)}$。对$\displaystyle{\bar{X}}$进行标准化，定义$\displaystyle{Z=\frac{\bar{X}-\mu}{\sqrt{ \frac{1}{n} }}}=\sqrt{ n }(\bar{X}-\mu)$，因此有

$$\tag{1.3}
\begin{align}
P_{H_{0}}\left\{\bar{X}\in \mathbb{D}\right\}=P\left\{\sqrt{ n }(1-\mu)<Z<\sqrt{ n }(1.05-\mu)\right\}=\Phi(\sqrt{ n }(1.05-\mu))-\Phi(\sqrt{ n }(1-\mu))
\end{align}
$$

其中$\displaystyle{\Phi}$是标准正态分布的CDF。

$\displaystyle{\mathbb{D}}$是否可以作为拒绝域取决于所选的显著性水平$\displaystyle{\alpha}$，只要$\displaystyle{P_{H_{0}}\left\{\bar{X}\in \mathbb{D}\right\}}$就可以认为$\displaystyle{\mathbb{D}}$可以作为拒绝域。

只要用$\displaystyle{\mathbb{D}}$作为拒绝域得到的检验结果是拒绝原假设，我们就可以下结论说在$\displaystyle{\alpha}$的显著性水平下认为原假设不成立。然而我们这里有可能会犯第一类错误，即拒绝了实际上成立的假设。不妨设$\displaystyle{\mu=1.5,n=100,\alpha=0.05}$，我们使用以下代码进行模拟

```R
n <- 100

mu <- 1.5

z_lower <- (1 - mu) * sqrt(n) # 对应于 barX = 1
z_upper <- (1.05 - mu) * sqrt(n) # 对应于 barX = 1.05

p_value <- pnorm(z_upper, mean = 0, sd = 1) - pnorm(z_lower, mean = 0, sd = 1)

print(paste("μ =", mu))

print(paste("P(H0: μ ≥ 0 | 1 < X̄ < 1.05) =", p_value))

alpha <- 0.05

if (p_value < alpha) {
  print("拒绝原假设 H0，在显著性水平 alpha 下有足够的证据反对原假设。")
} else {
  print("不拒绝原假设 H0，没有足够的证据反对原假设。")
}
```

运行结果为

```Console
[1] "μ = 1.5"
[1] "P(H0: μ ≥ 0 | 1 < X̄ < 1.05) = 3.11102155285087e-06"
[1] "拒绝原假设 H0，在显著性水平 alpha 下有足够的证据反对原假设。"
```

可以看到我们这里虽然拒绝了原假设$\displaystyle{H_{0}}$，但是显然原假设是正确的，也就犯了第一类错误。

3. 假设检验的原理是什么？与反证法有何联系和区别？
	1. 假设检验是统计学中的一种方法，用于判断样本数据是否支持某个假设（通常称为零假设）。反证法是一种逻辑推理的方法，通常用于数学证明。
	2. 假设检验的原理
		1. **提出假设**：
			1. 零假设（$\displaystyle{H_{0}}$）: 这是要检验的基本假设，通常表示“没有效果”或“没有差异”。
			2. 备择假设（$\displaystyle{H_{1}}$）: 这是与零假设相对立的假设，表示存在某种效果或差异。
		2. 选择显著性水平（$\displaystyle{\alpha}$）:
			1. 这是决定拒绝零假设的临界值，通常设定为0.05或0.01。
		3. 收集数据并进行统计分析:
			1. 根据样本数据，计算一个统计量（如t值、z值等）。
		4. 计算$\displaystyle{p}$值:
			1. $\displaystyle{p}$值表示在零假设为真的情况下，观察到当前或更极端的数据的概率。
		5. 做出决策:
			1. 如果$\displaystyle{p}$值小于显著性水平$\displaystyle{\alpha}$，则拒绝零假设；如果p值大于或等于显著性水平，则不能拒绝零假设。
	3. 联系
		1. 形式相似：
			1. 在假设检验中，零假设（$\displaystyle{H_{0}}$）可以看作是待反驳的命题。通过统计分析和计算出$\displaystyle{p}$值，如果得出与零假设相悖的结果，即可以“反证”其成立。
		2. 逻辑推理：
			1. 两者都涉及逻辑推理：假设检验通过数据和统计方法支持或反对假设，而反证法通过推理找到矛盾来支持原命题。
	4. 区别
		1. 应用领域：
			1. 假设检验主要应用于统计学和数据分析，涉及对样本数据进行推断。而反证法通常用于数学证明和逻辑推理。
		2. 结果解释：
			1. 在假设检验中，拒绝零假设并不等同于证明备择假设为真，只是提供了证据支持。而反证法则是通过逻辑推理直接证实原命题的真。
		3. 结论的性质：
			1. 假设检验得到的是概率性的结论（例如，某种差异是否显著），而反证法则是确定性的结论（要么原命题为真，要么为假）。
